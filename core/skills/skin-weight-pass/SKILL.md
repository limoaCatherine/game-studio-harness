# 蒙皮权重怎么刷

## 何时用

- 绑定完成后要交可播蒙皮
- 关节飞肉、塌陷、穿透
- 每顶点影响骨超引擎上限
- 动画开工前要过权重

## 怎么做

### 1. 定标准与姿势集

1. 写影响骨上限、权重归一化、压缩/量化策略（引擎侧）；上限向用户索取项目档，不猜。
2. 列必测极端姿：肩高举、肘全屈、深蹲、扭腰、跪地、武器高举等；与 bind-rig 极端姿截图对齐。
3. 确认绑定/网格版本匹配；版本号写进工作卡，旧骨新模分开处理到对齐为止。
4. 打开权重工具与镜像选项；确认对称轴与角色中线一致。
5. 布料/头发若独立网格，单独列入姿势集，不与身体一把刷混记。
6. 约定阻塞标准：飞肉穿模可见、体积塌陷超观感、影响骨超限——任一条不过继续修到过。
7. 从 bind-rig 交接包核：骨架版本号、极端姿截图、Socket 表路径；缺任一则停本步向绑定索取。

**做到**：姿势集列表与影响骨上限写入工作卡；版本对齐。

### 2. 按姿势刷权重

1. 逐姿势看飞肉/穿透/塌陷；局部加/减权；对称部位先镜像再查非对称装备。
2. 关节弯折前后比轮廓体积，塌陷超观感阈值必须回修（阈值向用户索取或按内部约定）。
3. 布料/头发权重与刚体约束分开记，不混一把刷导致互相抢权重。
4. 问题→修→同姿势复测；姿势集全部过完再交，不只看 T-pose。
5. 用权重彩色显示核平滑带是否过宽/过窄；过宽导致果冻，过窄导致折痕。
6. 打开线框+实体双视图确认关节环形边是否跟得上变形。
7. 刷权时随时保存增量版本；坏权重可回退，保留可回退链。

**做到**：姿势集阻塞问题清零；体积保持可接受。

### 3. 技术限复核

1. 扫每顶点影响骨数，超限合并或裁剪到上限内；再归一化权重。
2. 开引擎压缩/量化预览，修压缩后炸点或抖动。
3. LOD 网格权重同步策略写清（重算/拷贝/禁独立）；LOD 蒙皮齐备再进包。
4. 导出后在引擎播一段攻击/下蹲，确认无新增飞肉。
5. 检查挂点 Socket 在极端姿下是否漂；漂回绑修或局部权重。
6. 记录剩余非阻塞瑕疵与规避动作（如「勿极度后仰」），交动画可见。
7. 影响骨扫描结果截图/日志贴进工作卡；超限顶点列表导出，合并/裁剪后复扫至 0 超限。

**做到**：影响骨合规；压缩预览无新阻塞；LOD 策略明确。

### 4. 交给动画

1. 蒙皮版本路径交给 `anim-set-checklist`；旧路径标废弃。
2. 附极端姿通过截图与影响骨扫描结果摘要。
3. 确认未顺手改绑定层级；若改了必须升骨架版本并通知。
4. 动画侧打开即播冒烟：idle↔攻击↔下蹲；失败回本流程修权重，不甩锅动画曲线。
5. 把规避动作写入状态机备注，避免策划配出必现炸姿。
6. 清理测试姿态层与临时刷权历史，保持文件干净。
7. 交活动画前再开权重彩色总览：无大面积未刷/零权岛；有则回步骤 2 补刷。

**做到**：动画侧可引用稳定蒙皮；规避项可见。

### 5. 引擎蒙皮回归

1. 引擎导入蒙皮网格后播极端姿动画集（或手动摆姿）：飞肉/穿模阻塞清零。
2. 开调试显示骨骼影响数或等价工具，确认≤上限。
3. LOD 切换时权重无炸；若 LOD 独立蒙皮则各级都过极端姿。
4. 压缩预览开关对比：量化后抖点已修。
5. 交动画附：版本路径、通过姿势列表、规避动作、影响骨扫描截图。
6. 发现需改绑：停蒙皮回 `bind-rig-checklist`，升骨架版本后再刷。
7. 回归包勾选：极端姿集、影响骨≤上限、LOD 切换、压缩开关对比；任红项继续修到过。

**做到**：引擎极端姿通过；交动画材料齐。

## 做到

- 约定极端姿测完；飞肉/塌陷阻塞清零；每顶点影响骨 ≤ 上限
- 压缩/量化后预览可接受；LOD 权重策略写清
- 版本路径可被动画集引用

## 失败回哪一步

- 交接包缺版本/截图、上限未写 → 回步骤 1（向绑定索齐）
- 姿势集飞肉/塌陷未清、只过了 T-pose → 回步骤 2
- 影响骨超限、压缩炸点、LOD 未蒙皮 → 回步骤 3（炸点回 2 局部权）
- 冒烟穿模、规避项未写 → 回步骤 3/2
- 引擎新增飞肉/需改绑 → 回步骤 2 或 `bind-rig-checklist` 升骨架后再刷

下一步常接：`anim-set-checklist`。
## 加厚：影响骨上限与压缩预览

### A. 影响数分档（公开引擎常见默认）

1. 主角/近景默认每顶点 ≤4 骨影响；群众/远景 LOD 可压到 2；>4 仅在测量证明变形收益大于 GPU 成本且项目允许时申请。
2. 导出前在 DCC 执行「按上限剪裁+归一化」；引擎导入端再设皮肤权重上限作双保险，但以 DCC 剪裁结果为准避免运行时静默丢权。
3. 压缩/量化预览：按项目中间件打开权重压缩预览，看肩肘膝是否出现阶梯塌陷；有则回修权重分布再压。
4. 幽灵影响：权重≈0 仍占槽的骨清掉，保证有效影响数真实 ≤上限。
5. 镜像：中线轴与骨架对称约定一致；不对称装备区禁止盲镜像，单独刷并截图。
6. 单角色尽量单一蒙皮渲染组件（少多段蒙皮叠加），附加物用挂点或独立短骨并记维护成本。

### B. 极端姿验收清单（阻塞）

1. 肩高举、肘全屈、深蹲、扭腰、跪地、武器高举——每项截图存档；飞肉/穿模/体积塌陷任一条阻塞。
2. 布料/头发分网格分姿势集；与身体抢权重导致果冻则拆开重刷。
3. 交动画前：绑定版本号、权重版本号、姿势截图包、已知限制一页纸齐全。

**不合格回**：上限未定→步骤1；只过 T-pose→步骤2；压缩后塌→步骤3（剪裁/预览）；交包缺版本→补交接再放行。

## 工具锚点（live mcp.json）

- `blender-mcp`：刷权重/镜像/导出；先 `tools/list`。
- `cascadeur`：极端姿参考（可选）。
- `gamedev-mcp`：引擎影响骨调试与压缩预览。
- `ffmpeg`：极端姿播测录像。
- **DoD 文件信号：** 影响骨扫描截图≤上限；极端姿通过列表；蒙皮版本路径；规避动作备注。
