# 多工具适配

技能、职种、菜单脚本的**唯一正文**在 `cursor/`。`adapters/registry.json` 只登记各 AI 编程工具的家目录。安装器先拷到共享运行时 `~/.gsh`，再按 `--tools` 落到各工具。

## 落点

| id | 产品 | 用户宪法 | 技能 | 职种 | 备注 |
|---|---|---|---|---|---|
| `cursor` | Cursor | `~/.cursor/rules/全局.mdc` | `~/.cursor/skills` | `~/.cursor/agents` | 钩子、MCP 档位、发现阶段最完整 |
| `claude` | Claude Code | `~/.claude/CLAUDE.md` | `~/.claude/skills` | `~/.claude/agents` | 项目根另写 `CLAUDE.md` |
| `codex` | OpenAI Codex | `~/.codex/AGENTS.md` | `~/.agents/skills` | `~/.codex/agents` | 遵循官方 AGENTS.md 链；注意 32KiB 默认上限，宪法已压短 |
| `grok` | Grok Build / grokbot | `~/.grok/AGENTS.md` | `~/.grok/skills` | `~/.grok/agents` | 官方也兼容 Cursor / Claude 目录 |
| `deepseek` | DeepSeek Harness | `~/.dsh/AGENTS.md` | `~/.dsh/skills` 与 `~/.agents/skills` | — | 默认读 AGENTS.md / CLAUDE.md |

业务根一律写 `AGENTS.md` 与 `CLAUDE.md`（同一份短宪法），再加 `.harness/` 档案柜。

## 各工具还要自己装什么

适配层**不代替**官方安装包。

| 工具 | 你要先装 | 本仓替你做的 |
|---|---|---|
| Cursor | [cursor.com](https://cursor.com) | 规则、钩子、技能、职种、`~/.cursor/harness` |
| Claude Code | 官方 CLI / IDE 扩展 | `~/.claude/{CLAUDE.md,skills,agents}` |
| Codex | [Codex CLI](https://developers.openai.com/codex) | `~/.codex/AGENTS.md` + `~/.agents/skills` |
| Grok | [Grok Build](https://docs.x.ai/build/overview)（`GROK_HOME` 默认 `~/.grok`） | `~/.grok/{AGENTS.md,skills,agents}` |
| DeepSeek Harness | [deepseek-ai/deepseek-harness](https://github.com/deepseek-ai/deepseek-harness)（`DSH_HOME` 默认 `~/.dsh`） | `~/.dsh/AGENTS.md` + skills |

不装某工具就不要把它写进 `--tools`。没写的家目录不会被创建。

## 运行时深度（如实）

| 能力 | Cursor | Claude | Codex | Grok | DSH |
|---|---|---|---|---|---|
| 短宪法 / 开场读序 | 有 | 有 | 有 | 有 | 有 |
| 技能 SKILL.md | 有 | 有 | 有 | 有 | 有 |
| 职种子代理 | Cursor agents | `.claude/agents` | 角色文件 | `.grok/agents` | 视发行版本 |
| 会话档案柜 `.harness` | 有 | 有 | 有 | 有 | 有 |
| 生命周期钩子 | `hooks.json` | 项目 settings 可再挂 | 视版本 | `.grok/hooks` 可再挂 | 视插件 |
| MCP 懒接档位 | `mcp-tiers.json` | 用项目 `.mcp.json` | 用 Codex MCP | 用 `~/.grok/config.toml` | 用 DSH 插件配置 |

宪法与写隔离在五套上相同。钩子和外接档位以 Cursor 为最完整实现；其他工具先保证「读得懂怎么做」，再按各自官方配置接 MCP。

## 怎么用（装完后）

1. 用对应工具打开业务根。
2. 改 `.harness/surfaces.json`。
3. 写 `.harness/sessions/<短名>/loadplan.json`。
4. `python %USERPROFILE%\.gsh\harness\scripts\生成会话能力名单.py <短名>`
5. 确认 `activated.json` 的 `ok=true`，职种没有预展开整条 `skills`。
