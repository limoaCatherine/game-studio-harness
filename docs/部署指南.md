# 部署指南

## 最短路径

1. 安装 [Python 3.11+](https://www.python.org/downloads/)（勾选 PATH）。
2. 安装你要用的 AI 工具：Cursor、Claude Code、Codex、Grok Build、DeepSeek Harness，可只装一部分。
3. 克隆本仓，双击 `一键部署.bat`，填写业务根。
4. 看到 `ok architecture install`。
5. 用对应工具打开业务根，改 `.harness/surfaces.json`。

```powershell
.\一键部署.ps1 -Workspace D:\MyStudio
.\一键部署.ps1 -Workspace D:\MyStudio -Tools cursor,claude,codex
.\一键部署.ps1 -CursorOnly -Tools grok,deepseek
python install.py --workspace D:\MyStudio --tools all
python verify_install.py --workspace D:\MyStudio --tools all
```

`--dry-run` 只打印将拷路径。`--write-mcp` **仅当**目标还没有 `~/.cursor/mcp.json` 时，从示例写一份无密钥骨架。已有现网配置时不要加这个开关。

`--isolate-root` 把所有家目录改写到探测树，用于验收，不碰真实 `~/.cursor` / `~/.claude` 等。

## 装完自检

| 应存在 | 含义 |
|---|---|
| `~/.gsh/AGENTS.md` | 共享宪法 |
| `~/.gsh/skills/route-task/SKILL.md` | 定档技能在 |
| `~/.gsh/harness/catalog.json` | 菜单已生成 |
| 已选工具的宪法文件 | 见 [适配.md](适配.md) |
| `<业务根>/.harness/surfaces.json` | 正式面地图在（还要改路径） |
| `<业务根>/AGENTS.md` 与 `CLAUDE.md` | 项目级入口 |

接线自检（cwd = 业务根）：

```text
python %USERPROFILE%\.gsh\harness\scripts\接线自检.py
```

架构是否落地以 `verify_install.py` 为准。缺 Excel / Unity 时外接健康检查红灯，不算架构失败。

## 失败表

| 现象 | 处理 |
|---|---|
| 找不到 Python 3.11+ | 安装并勾选 PATH，重开终端 |
| `missing cursor/` | 在仓根运行，不要只拷 `install.py` |
| `unknown tool` | `--tools` 只能是 cursor,claude,codex,grok,deepseek |
| catalog 缺 skill | 看 `~/.gsh/skills` 是否拷全，再跑安装器 |
| 某工具读不到技能 | 确认该工具写进了 `--tools`，并看 [适配.md](适配.md) 落点 |
| 现网 mcp.json 被问要不要覆盖 | 安装器默认保留；不要加 `--write-mcp` |

## 升级

拉新后在仓根再跑一次 `一键部署.ps1`。业务根里已有的 `.harness` 文件不会被覆盖（`merge_missing`）。宪法与技能以仓内 `cursor/` 为准覆盖用户级拷贝。
