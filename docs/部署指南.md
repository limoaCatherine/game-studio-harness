# 部署指南

## 最短路径

1. 安装 [Python 3.11+](https://www.python.org/downloads/)（勾选 PATH）和 [Cursor](https://cursor.com)。
2. 克隆本仓。
3. 双击 `一键部署.bat`，填写业务根。
4. 看到 `ok architecture install`。
5. 用 Cursor 打开业务根，改 `.harness/surfaces.json`。

命令行：

```powershell
.\一键部署.ps1 -Workspace D:\MyStudio
.\一键部署.ps1 -CursorOnly
python install.py --workspace D:\MyStudio
python verify_install.py --workspace D:\MyStudio
```

`--dry-run` 只打印将拷路径。`--write-mcp` **仅当**目标还没有 `~/.cursor/mcp.json` 时，从示例写一份无密钥骨架。已有现网配置时不要加这个开关。

## 装完自检

| 应存在 | 含义 |
|---|---|
| `~/.cursor/rules/全局.mdc` | 宪法已落地 |
| `~/.cursor/skills/route-task/SKILL.md` | 定档技能在 |
| `~/.cursor/agents/` 下有职种 md | 职种在 |
| `~/.cursor/harness/catalog.json` | 菜单已生成 |
| `<业务根>/.harness/surfaces.json` | 正式面地图在（还要改路径） |

接线自检（cwd = 业务根，且已有非探测会话）：

```text
python %USERPROFILE%\.cursor\harness\scripts\接线自检.py
```

`握手四层.py` / `整接.py` 在无软件机上可能因 `mcp-health.json` 失败。架构是否落地以 `verify_install.py` 为准。

## 失败表

| 现象 | 做 |
|---|---|
| 找不到 python | 安装 3.11+ 并重开终端 |
| 菜单无 id | 跑 `刷新菜单.py`；仍无则对照 `doctor` |
| 生成名单报 needs_mcp 不在 catalog | 先有 `mcp.json` 键，或先不要点那条 skill |
| 职种把路径技能预展开 | 不要改生成脚本口径；查 `全局.mdc` 是否含「不预展开」 |
| 开场没有现行卡 | 业务根缺 `.harness` 或 `sessions/LATEST` |
| 想加一层 | 停。先转向、改计划、写决策 |
| MCP 全红 | 先读 [工具总览](工具/总览.md)；无宿主时忽略健康红灯 |

## 升级本仓

在仓根 `git pull` 后再跑一遍 `一键部署.ps1`。同名架构文件会被覆盖；业务根已有的 `.harness` 文件**不会**被覆盖。
