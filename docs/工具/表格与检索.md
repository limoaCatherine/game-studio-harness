# 表格与检索

## excelMCP（核心）

**要装**

- Microsoft Excel（桌面版，COM 可用）
- Python 3.11+
- 本机 Excel MCP 后端（示例入口 `${HARNESS_APPS}/mcp/excel-unified/server.py`）
- COM 助手：`${DOTNET_TOOLS}/mcp-excel.exe`（环境变量 `EXCEL_COM_CMD`）

**怎么用**

1. 把 `excelMCP` 写进 `~/.cursor/mcp.json`，**不要**套 `lazy_stdio.py`。
2. 改正式表前先 `xlsx_probe`，再 `xlsx_sandbox_clone`，只在副本上改。
3. 写完按 `excel-format` 排本轮改过的区。
4. 晋升用 `xlsx_merge_changeset`，只合记录格。禁止整本覆盖正式簿。
5. 审阅只对沙箱 `show=true`。审阅完释放 COM。

技能：`excel-read` `excel-com-write` `excel-format`。无 Excel 时架构仍可用，只是改不了表。

## everything-search（懒接）

**要装**

- [voidtools Everything](https://www.voidtools.com/)（建议开服务）
- 对应 MCP 后端（示例 `${HARNESS_APPS}/mcp/everything-mcp`）

**怎么用**

- 用文件名、通配、`path:`、`ext:` 搜本机，不要拿它当内容全文库（除非 Everything 已建内容索引）。
- 大范围找资源、导出物、日志时再调。启动不必拉起。
