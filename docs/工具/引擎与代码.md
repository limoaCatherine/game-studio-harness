# 引擎与代码

## gamedev-mcp（懒接）

**要装**

- Unity（或你接线的引擎宿主）
- `gamedev-mcp-server`（示例 `--port=28080`）
- 引擎侧插件按该服务器文档安装

**怎么用**

- 空等 Unity 一次 `tools/list` 大约十秒级，必须懒接，否则会堵 Excel。
- 只写 `surfaces.json` 里 `kind=engine` 的沙盒根。
- 典型动作：列场景、找对象、跑测试、读控制台。正式工程不要当试验盘。

环境变量见 registry：`MCP_BIND` `MCP_PLUGIN_PORT` 等。探活也可设 `GAMEDEV_MCP_EXE`。

## roslyn-mcp（懒接）

**要装**

- .NET SDK
- `dotnet tool` 安装 Roslyn MCP（示例 `${DOTNET_TOOLS}/roslyn-mcp`）
- 目标解决方案能被 MSBuild 加载

**怎么用**

- 查符号、引用、重命名预览，再按确认令牌应用。
- 不要用文本替换代替语义重命名。
- 只用到 C# 时再拉，不必开场全量。

## docker-mcp（懒接）

**要装**

- Docker Desktop，守护进程在跑
- 镜像 `gavinlucas/docker-mcp-server:latest`（或你改过的等价镜像）

**怎么用**

- `mcp.json` 里 `command` 用 `${DOCKER}`，不要写死 `C:\Program Files\...`。
- 工具表过百，必须懒接。
- 只操作你有权限的容器 / compose。不要在文档或仓里放 registry 密码。

## chrome-devtools（懒接）

**要装**

- Node.js（含 npx）
- Chrome / Edge
- 包：`chrome-devtools-mcp@latest`

**怎么用**

- 验证 Web 调试页、本地文档站、工具 UI。
- 不要用浏览器自动化去绕过缺失的 MCP。
- 登录墙、验证码、破坏性确认应停下来交给人。
