# 工具总览

本仓**不附带软件**。一键部署只落规则、技能、职种和注册逻辑。下面按用途列出 36 条外接：要装什么、何时用、怎么接到 Cursor。

权威注册表：同目录 `mcp-registry.json`。档位：`cursor/harness/mcp-tiers.json`（核心仅 `excelMCP`，其余懒接，`miro` 走 URL）。

## 怎么接到本机

1. 宿主软件装好，并能手动打开。
2. 对应 MCP 后端按各节安装（uvx / npx / 本机 server）。
3. 复制 `cursor/mcp.json.example` 到 `~/.cursor/mcp.json`（若还没有），把 `${PYTHON}` `${NPX}` `${HARNESS_APPS}` 和密钥占位符换成你的机器值。
4. 跑 `python %USERPROFILE%\.cursor\harness\scripts\应用外接档位.py`。
5. 核心条目不要套 `lazy_stdio.py`。密钥只进本机密钥管理处或本机 `mcp.json`，不要提交。

无宿主时：**不要**为了让健康检查变绿去装一堆软件。架构已经可用。

## 运行时

| 占位符 | 含义 |
|---|---|
| `${PYTHON}` | Python 3.11+ |
| `${NPX}` / `${NODE}` | Node.js 自带的 npx / node |
| `${UV}` / `${UVX}` | Astral uv |
| `${DOCKER}` | Docker CLI |
| `${DOTNET_TOOLS}` | `dotnet tool` 安装目录 |
| `${MCP_BOOT}` | `~/.cursor/harness/mcp-boot` |
| `${HARNESS_APPS}` | 你约定的本机工具根（DCC 与自建 MCP 后端） |

## 最低可工作集

只想先跑通制作会话，**不必**装齐 36 个：

1. Cursor + Python 3.11+（本仓一键部署）
2. 若要改表：Excel + `excelMCP` 后端
3. 其余用到再装

## 档位提醒

- **核心直连**：现在只有 `excelMCP`。启动就要能 `tools/list`。
- **懒接**：第一次真正 `tools/call` 才拉进程。工具表过百或会空等宿主的必须懒接。
- **URL**：`miro` 不套本机包装。
- **HTTP 桥**：`cascadeur` 已是桥；脚本服务没开时不可挡发现。
