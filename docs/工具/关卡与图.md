# 关卡与图

| id | 要装的软件 | 用法要点 |
|---|---|---|
| `tiled` | [Tiled](https://www.mapeditor.org/)；npx `tiled-mcp-server` | `--project-dir` / `TILED_PROJECT_DIR` 指向地图目录。改图前预览，再 `apply_change_set`。 |
| `ldtk` | [LDtk](https://ldtk.io/) + host MCP | 2D 关卡字段、实体。`LDTK_EXE` `LDTK_PROJECT_DIR`。 |
| `magicavoxel` | MagicaVoxel + host MCP | 体素草案。`MAGICAVOXEL_EXE` 与工作区目录。 |
| `excalidraw` | 无需桌面软件；本机 excalidraw-mcp | 架构块、流程图。`output_path` 用绝对路径。技能 `diagram-pack`。 |
| `xmind` | [XMind](https://xmind.app/) + xmind-mcp | 树 / 大纲，不拿 relationship 当流程箭头。 |
| `miro` | 浏览器即可；官方 `https://mcp.miro.com/` | **URL 直通**，不套 lazy_stdio。先 OAuth。免费档少打往返。画布协议见 Miro canvas skill。 |

关卡技能：`level-goals-spec` `blockout-pass` `encounter-script` `pacing-pass`。图种分流见 `diagram-pack`。
