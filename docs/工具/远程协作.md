# 远程协作

## lark-mcp（懒接）

**要装**

- Node.js（npx）
- 飞书开放平台应用（机器人权限按你要用的 API 开）
- 包：`@larksuiteoapi/lark-mcp`

**怎么用**

```text
npx -y @larksuiteoapi/lark-mcp mcp -a ${LARK_APP_ID} -s ${LARK_APP_SECRET}
```

- 示例里 `-a` / `-s` 必须是占位符，不能是真值。
- 真值只进本机密钥管理处或本机 `mcp.json`，不要提交、不要写回本仓。
- 典型：搜文档、读知识库、发明细、建多维表记录。先确认应用有对应范围。

本仓验收脚本会拒绝看起来像字面密钥的 `-a` 参数。
