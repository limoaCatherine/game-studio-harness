# 职种索引

仓库根 `agents/` 是唯一真相。共 35 条。职种是路径，不是开场必读清单。

## 制作与方向

| ID | 解决什么 | 路径技能数 |
|---|---|---:|
| `producer` | 制作人。负责里程碑目标、构建验收推动、发版说明口径与跨职种制作推动。触发：里程碑,定档,发版,构建验收,制作排期。 | 7 |
| `associate-producer` | 执行制作人。负责拆交付包、跨组协调、阻塞闭环与验收前齐套催收。触发：执行跟进,交付包,跨组协调,日会,阻塞闭环,齐套催收。 | 5 |
| `project-manager` | 项目管理。负责风险台账、依赖图与定期状态摘要，给纠偏选项。触发：风险台账,依赖图,周报,阻塞,status digest,纠偏。 | 4 |
| `creative-director` | 创意总监。负责体验支柱定稿、切片体验批注、跨职种 fantasy 冲突裁决与 scope-cut 原则。触发：支柱,pillar,体验评审,experience critique,砍范围,scope cut,方向冲突,fantasy,垂直切片验收。 | 4 |

## 系统与数值

| ID | 解决什么 | 路径技能数 |
|---|---|---:|
| `systems-designer` | 系统策划。负责系统索引、功能 GDD 切片与规则可行性预检。触发：系统索引,GDD,规则可行性,系统接口,feature slice,隐式系统,队首设计谁。 | 4 |
| `combat-designer` | 战斗策划。负责战斗流程、技能组与手感验收清单。触发：战斗流程,技能组,手感,combat flow,skill kit。 | 7 |
| `combat-numeric-designer` | 战斗数值策划。负责属性、公式、克制与技能数值；改表走表格写入配方。触发：战斗数值,属性表,伤害公式,克制,TTK,技能数值。 | 9 |
| `economy-numeric-designer` | 经济数值策划主路径：串起产销循环、产销地图、物价、通胀与表晋升，并挂接事件节点。触发：经济循环,产销,物价,通胀,货币,经济数值。 | 6 |
| `progression-numeric-designer` | 养成数值策划主路径：串起成长曲线、解锁节奏、产销接口、属性挂接与表晋升，并挂接事件节点。触发：养成曲线,成长曲线,战力曲线,养成数值,解锁节奏。 | 7 |
| `monetization-designer` | 商业化策划。负责付费点、IAP/礼包/通行证目录与商业化 KPI 口径。触发：商业化,IAP,SKU,付费点,KPI,ARPU,通行证,礼包,商店目录。 | 2 |
| `liveops-designer` | 活服策划。负责活动日历、活动规格与奖励邮件安全检查。触发：活动日历,liveops,档期,赛季,活动案,event spec,邮件奖励,补发,运营节奏。 | 3 |

| `server-engineer` | 服务端开发工程师。契约→实现校验→存档迁移→反作弊挂点→冒烟交付。触发：服务端,API,存档Schema,契约测试,幂等,迁移回滚。 | 4 |
| `server-combat-engineer` | 服务端战斗开发工程师。负责战斗权威、结算校验与反作弊协作。触发：战斗权威,结算,伤害校验。 | 5 |
