# 图像与媒体

| id | 要装的软件 | 用法要点 |
|---|---|---|
| `krita-mcp` | [Krita](https://krita.org/) + krita-mcp（默认可 `KRITA_URL=http://127.0.0.1:5678`） | 先 `krita_health`。选区、描边、导出。Krita 要开对应脚本服务。 |
| `gimp` | [GIMP](https://www.gimp.org/) + gimp-mcp（`uv run`） | 图层、色调、导出。先 `check_server` / `list_images`。 |
| `inkscape` | [Inkscape](https://inkscape.org/) + inkscape-mcp | 矢量、SVG、批量。`INKSCAPE_PATH` 指向 bin。 |
| `imagemagick` | [ImageMagick](https://imagemagick.org/) + imagemagick-mcp（Node） | 批转、裁切、精灵图、水印。命令行能力强，先小图试。 |
| `ffmpeg` | [FFmpeg](https://ffmpeg.org/) 在 PATH + ffmpeg-mcp | 转码、截帧、混音、烧字幕。长任务看进度，不要默默覆盖源文件。 |
| `audacity` | Audacity + host MCP | launch-only。精细剪辑仍在 GUI。 |
| `fmod-cli` | FMOD Studio 自带 `fmodstudiocl` | **主路径**：诊断、打 Bank、导出 GUID。技能 `fmod-bank-build`。 |
| `fmod-studio` | FMOD Studio + TCP 脚本口 + fmod-studio-mcp | **辅路径**：事件编辑在 Studio GUI。工具表过百，必须懒接。 |
| `pureref` | PureRef + host MCP | launch-only。参考板给人看，不代工排版审美。 |

音频技能：`audio-fmod-checklist`。FMOD 工程路径用环境变量，不要写进公开仓。
