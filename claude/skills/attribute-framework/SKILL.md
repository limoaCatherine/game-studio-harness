# 属性框架怎么定

## 何时用

- 新建或重构属性集，公式要稳定变量名
- 派生属性口径不一致或出现环依赖
- 上下限/溢出/快照行为未写清
- 成长曲线或 UI 要挂属性主键

## 怎么做

### 1. 枚举主键与语义

**做**
1. 打开现有属性表/面板截图/公式草稿；列出一级属性与资源类候选：稳定 ID、显示名、语义一句、单位、是否进面板。
2. 把运行时标签、状态标记、临时计数器从属性表剔出，另记「非属性」清单，运行时标签/状态标记另记「非属性」清单。
3. 对照 canon/命名规范：ID 冲突则并列「旧名|新名|处置」，ID 冲突并列「旧名|新名|处置」请用户裁。
4. 标本里程碑冻结主键集与可继续加的扩展位；扩展位写「允许加 / 本版不加」两类。
5. 向用户确认面板展示集合：哪些进角色卡、哪些仅战斗内可见；缺档位数字先索取再往下。
6. 输出主键清单草稿供口头复述：听者能不看表说出每个 ID 的语义与单位。

**做到**：主键清单可逐条指表列；非属性项已剔除；冻结集与扩展位分栏可见；失败→回本步 改 属性主键清单或扩展位边界

### 2. 定义派生与聚合 DAG

**做**
1. 对每个派生属性写：输入属性集、聚合方式（加/乘/曲线/软帽）、计算时机（改属性时/开战快照/每次命中）。
2. 用箭头画依赖 DAG（纸面或图）；发现环则拆输入、改时机或拆成中间属性。
3. 写清面板展示值与战斗内有效值是否允许分叉：允许则写分叉时机与展示优先级；不允许分叉则声明「永远同源」。
4. 隐藏乘区（职业系数、暗改成长）必须登记为派生或显式修饰项；未登记不得进结算。
5. 给 2 套聚合方案（更加算友好 / 更乘算克制）+利弊，请用户选定主聚合风格后再填表。
6. 派生表字段对齐：派生 ID、输入集、聚合、时机、输出单位；缺字段先补列再写数。

**做到**：派生表含派生ID/输入集/聚合/时机/输出单位；DAG 拓扑无环；面板与战斗分叉规则写死；失败→回步骤 1 改 主键或派生输入集（断环）

### 3. 快照、钳制与溢出

**做**
1. 快照三级：开战锁定哪些、施放锁定哪些、永远实时哪些；逐属性填入一列，逐属性填快照列。
2. 每属性写 min/max（或软帽曲线名）与越界策略：钳制 / 拒绝写入；越界策略写钳制或拒绝写入。
3. 超额治疗、护盾溢出、暴击倍率上限等写独立溢出规则，并注明跳字与服务器权威是否同规则。
4. 资源类（怒气/能量）写耗尽后果与回复是否战斗外保留；与 combat-flow 资源轴主键对齐。
5. 列出至少：0 值、满值、越上/下限一步 的边界场景，作为下游公式验算必跑输入。
6. 把边界规则表与主键表交叉核对：有主键必有边界行，无边界行标红补齐。

**做到**：边界与快照行为可跑通边界场景；溢出有显式钳制/报错非静默；失败→回步骤 2 改 派生时机或资源类主键

### 4. 对齐下游并落表

**做**
1. 输出变量名清单给 damage-formula / progression / UI / 技能系数表；改名必须附全局替换计划（搜哪里、改谁）。
2. 产品表写入按 `excel-mcp-layers` 点读取/改动/格式；多表编排走 `attr-family-sync`；晋升走 `tunable-table-diff`。
3. 冻结本版主键集：冻结后新增属性必须走扩展位审批，冻结后新增属性走扩展位审批。
4. 与客户端属性面板、服务器权威属性模块各确认一次同名同单位；不一致先并列再裁。
5. 全文搜索旧属性别名；残留引用列入影响面，未清完不得宣称框架已切换。

**做到**：下游公式/成长/UI 引用同名主键；表字段可指 sheet.col；影响面列表齐；失败→回步骤 1 改 主键名或派生输出名

下一步常接：`damage-formula-pass`；成长挂接 `progression-curve`。

## 细则

### A. 基础值 / 当前值 / 修饰栈

1. 每个 `attr_id` 声明是否拆 `base_value` 与 `current_value`；修饰以栈或层表登记：`mod_id|op|value|source|duration`。
2. Instant 修饰改 base 或打一次性 current；Duration/Infinite 必须可驱散/可查询来源。
3. 面板读取策略：`show_base|show_current|show_both`；与战斗有效值分叉时写优先级。
4. 检查：加一条临时 buff 后 current 变、移除后回 base；日志打印 mod 栈。
5. 不合格：静默改 base 且无来源 → 回派生/修饰登记。

### B. 与公式、成长、资源轴交叉

1. 公式变量 ⊆ 主键∪派生输出；`rg` 公式草稿中的自由变量。
2. 成长表输出列名 = `attr_id`；转换系数表位置固定，溢出策略与本框架钳制一致。
3. 资源轴 `attr_key` 必须点名本框架资源类主键；`persist_ooc` 两边同值。
4. 边界必跑输入提供给 `damage-formula-pass` 验算槽。
5. 冻结后新增：走 `extension_slot` 审批，并更新影响面（公式/UI/成长）。
