# 绑定骨架怎么做

## 何时用

- 生产模可绑，要出可蒙皮骨架
- 模板层级/命名不合规；IK 残留偏移；武器/VFX 挂点要进字典

## 勾选主路径

### 1. 对照模板摆骨架

- [ ] 模板层级树/命名前缀/必要骨列表逐项勾
- [ ] 缺骨/多余骨进例外表（名、理由、是否破坏动画复用）；无理由不改必要骨
- [ ] 根骨朝向、单位、世界比例贴合；导出单帧确认前向轴
- [ ] 关节区对齐生产模环形边（肩腋肘腕髋膝踝）；对不齐先回建模
- [ ] 左右对称核验；非对称装备骨单独标注
- [ ] 大纲无垃圾定位器/默认名/无用中间约束

### 2. 装 IK 与约束并验可逆

- [ ] 按模板装四肢/脊柱 IK、极向、Aim/Parent；**IK 开↔关无残留偏移**
- [ ] 左右镜像控制器后右肢同等可用
- [ ] 控制器命名严格跟模板，禁止另造并存名
- [ ] 删临时点约束/断链转换/历史二次约束
- [ ] 绑定姿与稍屈肘膝姿确认约束优先级无跳变
- [ ] 若引擎另有绑定层：DCC 与引擎 IK 开关对齐后再交蒙皮

### 3. 挂 Socket 并与字典对齐

- [ ] 武器/背/腰/头/特效挂点：父骨、本地偏移、用途写入 Socket 表
- [ ] 挂点名与动画/特效事件字典**逐字同名**（大小写与下划线）
- [ ] 手↔背、拔刀收刀、打断收刀各走一遍：不炸、不飞、无世界残影
- [ ] 引擎挂测试网格播攻击：无穿手/漂移（漂则回调偏移并更新表）
- [ ] 主手/副手/收纳位分名；一用途一名
- [ ] Socket 表作唯一名源交 `vfx-skill-hook`/武器系统；旧名进废弃栏

### 4. 极端姿压力与导出交蒙皮

- [ ] 肩高举/深蹲/扭腰/跪地/回头/武器高举等极端姿：无阻塞万向锁/骨交错
- [ ] 绑层可修当场修；推蒙皮的标「蒙皮可补/绑必须改」
- [ ] 改层级或加辅助骨 → 升骨架版本并通知动画与蒙皮
- [ ] 极端姿截图进任务备注（蒙皮必测起点）
- [ ] 按管线导出；控制器/约束剥离策略合项目约定
- [ ] 引擎核对层级名/Socket/朝向；交 `skin-weight-pass` 附模板 diff、Socket 表、极端姿截图、版本号

## 做到

- [ ] 层级/命名符合模板或例外表齐备
- [ ] IK/约束可逆开关且无残留偏移
- [ ] Socket 表齐全且与事件字典逐字同名
- [ ] 极端姿已测并可接受或非阻塞已标注；引擎骨架可开并可交蒙皮

## 失败回哪一步

- 未合模板 → 回 1（未合不装 IK）
- IK 残留/镜像失败 → 回 2
- Socket 名漂/切换炸 → 回 3（必要时回 2）
- 极端姿需改层级 → 回 1/2，升版本后再压
- 引擎名/朝向不一致 → 回 4 导出策略后再交

下一步常接：`skin-weight-pass`。不写蒙皮刷权重与动画事件帧全文。

## 工具锚点（live mcp.json）

- `accurig`：文件/工作区级（validate_mesh_input / prepare_workspace / queue_open / list_outputs / handoff_notes）。不能 GUI 自动绑骨。
- `blender-mcp`：摆骨/IK/导出；先 `tools/list`。
- `rokoko`：动捕参考 — launch-only。
- `meshlab`：绑前网格清理 `convert_mesh`/`apply_filter`。
- `gamedev-mcp`：引擎骨架/Socket 预览。
- **DoD 文件信号：** Socket 表、模板 diff、极端姿截图、骨架版本号；引擎层级名一致。
