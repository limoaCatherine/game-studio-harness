# 付费 KPI 怎么定口径与定位

## 何时用

- 版本目标要落付费指标口径
- 转化漏斗某段异常
- 礼包/通行证效果需复盘
- 付费与经济投放口径打架

## 怎么做

### 1. 定义口径与漏斗

1. 写指标：付费率、ARPU/ARPPU、档位转化、复购、订阅留存等；每指标分子/分母/窗口/排除。
2. 画漏斗：曝光→点击→下单→到账→首日复购；每段事件名与日志字段。
3. 区分技术失败与意愿失败；不得混为「转化差」。
4. 与经济指标划界：不把投放量当收入；冲突口径并列请裁。
5. 排除规则含内部号、退款、测试账号；缺排除不得上看板。
6. 不合格：事件名在埋点表缺失 → 先补埋点再谈掉量。

**做到**：指标字典可复算且含排除；漏斗段事件字段可对读埋点表。

### 2. 对齐目标与基准

1. 写入版本目标带与对照基准（上版本/同品类字段）；向制作方索取，不编造业界平均。
2. 标本版本改动的变现点及其预期作用漏斗段。
3. 目标带与 iap 目录/活动日历对齐；无对应变现点的目标标「缺抓手」。
4. 口径变更单独记账；分母口径（DAU/付费用户）写死。
5. 输出目标-基准-变现点映射请确认。
6. 不合格：无抓手目标未标黄 → 回补映射。

**做到**：目标-基准-变现点映射已确认或标缺抓手；分母口径写死。

### 3. 支柱禁区与异常定位

1. 写不伤支柱禁区（强制广告打断核心循环、未披露的战斗付费优势等）。
2. P2W 风险灯与免费替代路径；取消支付与兑现失败纳入验收。
3. 定位异常段：对照漏斗哪一段掉量；证据为事件计数而非观感。
4. 异常动作：改展示/改目录/改入口 UX/补埋点——选项带影响面。
5. 分析侧拉不出事件则阻塞上架。
6. 不合格：禁区未写或异常无事件证据 → 回步骤 1/本步补齐。

**做到**：禁区与免费替代/P2W 灯写清；异常段有事件计数证据与干预选项。

### 4. 冻结口径与行动清单

1. 冻结口径表版本号；后续看板与复盘必须引用该版本。
2. 输出行动清单：Owner、依赖 skill（iap/calendar/ux）、验收信号。
3. 与 monetization-designer 付费点设计交接；本文件不写具体美术资源。
4. 入库文档仓；变更走影响面（谁看错分母）。
5. 复盘模板一行：口径版本、窗口、结论、下一动作。
6. 不合格：口径未冻结却开改目录 → 停手先冻。

**做到**：口径版本冻结；行动清单含 Owner/依赖/验收信号。

## 做到

- 指标字典可复算且含排除规则
- 漏斗段事件字段齐全可对读埋点表
- 禁区与免费替代路径写清
- 口径版本冻结且目标-变现点映射已确认或标缺抓手

## 失败回哪一步

- 步骤1（定义口径与漏斗）：事件名在埋点表缺失 → 先补埋点再谈掉量。
- 步骤2（对齐目标与基准）：无抓手目标未标黄 → 回补映射。
- 步骤3（支柱禁区与异常定位）：禁区未写或异常无事件证据 → 回步骤 1/本步补齐。
- 步骤4（冻结口径与行动清单）：口径未冻结却开改目录 → 停手先冻。
