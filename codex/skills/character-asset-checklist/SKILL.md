# 角色资产怎么验收入库

## 何时用

- 原画/三视图已定，开做可进引擎的角色生产模
- 外包回传按同一清单收口；绑皮前拓扑/UV/贴图/LOD 要达标

## 勾选主路径

### 1. 定档位与制作边界

- [ ] 对照定位（主角/精英/杂兵/展示）写清面数档、贴图尺寸档、是否高模烘焙
- [ ] 风格锚点色形材已批；剪影与三视图已批才开生产模
- [ ] 可拆部件（头/身/装备）与换装插槽需求列出
- [ ] 拓扑流向：肩腋肘腕髋膝环形边密度；交绑骨对齐区写清
- [ ] 命名前缀按 Domain/Type/Name/Variant 预占
- [ ] 档位与工期冲突时给减配选项，由决策方拍板

### 2. 建模 UV 与贴图收口

- [ ] 生产模：无非流形/重叠面/翻转法线；冻结变换后导出
- [ ] UV 岛按材质 ID 分区；接缝藏衣缝/硬边；棋盘格无严重拉伸
- [ ] 烘焙法线/AO/曲率等到目标贴图集；空岛与溢出标返工
- [ ] 贴图通道（基础色/法线/掩码）与着色器输入一一对应
- [ ] 高模仅作烘焙源，不进运行时包；高模↔低模差异表写清
- [ ] 换装共享 UV 处标注，防接缝错位

### 3. LOD 与导入引擎验收

- [ ] 按项目 LOD 比例生成各级；轮廓与面部关键环优先保留
- [ ] 导入预设：单位、前向轴、切线空间；导入日志无缩放/材质丢失阻塞警告
- [ ] 引擎内对比 T/A 姿、材质球、阴影；穿帮/黑面回 DCC
- [ ] LOD 各级可切换（距离标定交 `lod-budget-pass`）
- [ ] 碰撞简化体（若需）与可视网格分离命名
- [ ] 资产路径写入可引用注册；临时目录不进正式引用

### 4. 清单勾选与交接绑定/动画

- [ ] 网格、材质、贴图、LOD、命名、导入路径全部勾完
- [ ] 交绑前环形边与骨架模板对齐区无缺口
- [ ] 面数/贴图超档进例外表或返工，不静默超预算
- [ ] 外包用同一清单验收；缺项退回并标责任
- [ ] 版本号与变更说明写入资产备注
- [ ] 下游交接：`bind-rig-checklist` / `skin-weight-pass` / `import-validate`

## 做到

- [ ] 档位面数/贴图达标或例外已批
- [ ] UV/贴图通道与着色器输入对齐
- [ ] LOD 各级可导入切换，导入日志无阻塞警告
- [ ] 清单勾完且路径可被绑定/动画引用

## 失败回哪一步

- 档位空、三视图未批 → 回 1
- 拓扑/UV/通道问题 → 回 2
- 导入警告、LOD 不可切 → 回 3
- 超档未例外、对齐区缺口 → 回 2/4

下一步常接：`export-naming-gate` → `import-validate`；绑皮 `bind-rig-checklist`。不写绑定 IK 全文与风格宪法长文。

## 工具锚点（live mcp.json）

- `blender-mcp` / `meshlab` / `instant-meshes` / `xnormal`（`bake_xml` best-effort）
- `magicavoxel`：体素草稿（文件级工具）
- `materialpilot`（`app_get_status`…）/ `materialize`（launch-only）/ `krita-mcp`/`gimp`/`imagemagick`
- `pureref`：launch-only。边界：仅 status / launch / open_file / list_recent（文件级）；不能遥控 GUI。人工在应用内完成绘制/绑定操作；MCP 负责开工具与指文件。Goal C 深化前勿假装有画笔 API。
- `gamedev-mcp`：导入抽检
- **DoD：** 档位面数达标；导入日志无阻塞；路径可交绑定。
