# 通胀压力怎么测

## 何时用

- 版本投放加大或新 Source 上线前
- 购买力失控迹象需要复现
- 需要默认可控的熔断包
- 里程碑要求可复述的压力结论

## 怎么做

### 1. 定义压力情景

**做**
1. 写情景轴：投放倍率、Sink 参与率、付费渗透、活动叠加；每情景参数槽字段化以便复算。
2. 至少含：基准、水龙头×N、Sink 参与率过低、活动 Source 叠加；N 与参与率向用户索取。
3. 锚定实体来自 sink-source 风险清单；声明投影窗口（日/周/版本）。
4. 定义失败判据：顶满比例、关键 Sink 失效、物价锚漂移超阈（阈值为空槽，向用户要）。
5. 输出情景卡：情景名、参数、窗口、失败判据引用。
6. 情景参数全部来自字段名。
7. 失败判据阈值向用户索取并写入情景卡，缺判据停投影。
8. 不合格项写返工回到哪一步（步骤号）。

**做到**：≥3 情景参数可复现；失败判据明确。

### 2. 投影库存与购买力

**做**
1. 按情景用净流量字段做持有量随窗口变化的计算槽（空槽公式，填用户/表内数）。
2. 选定一篮子商品价带，投影「篮子可购次数」随窗口变化；只看库存会漏购买力塌陷。
3. 标首次触发失败判据的窗口点；区分 Source 过大 vs Sink 不足。
4. 记录投影用的表版本与参数快照，保证可复算。
5. 若缺净流量定义，先回 sink-source-map，不硬估。
6. 库存曲线与篮子可购次数同图或同表输出，便于对照。
7. 触失败点同时标「主因假设」：Source 过大或 Sink 不足。
8. 缺项目数字/档位时向用户索取，标假设的条目不得当事实引用。

**做到**：投影字段可算；触失败点可指。

### 3. 设计熔断选项

**做**
1. 选项池：降投放 / 加强 Sink / 限时货币加速过期 / 提高关键价档 / 活动 Source 开关。
2. 每选项写：触发条件字段、生效范围、回滚方式、对主环副作用。
3. 给 2～3 套组合+利弊，用户选定默认熔断包；熔断必须可回滚。
4. 熔断涉及表字段：沙盒 `excel-com-write`；开关类写配置键名。
5. 默认熔断包用可回滚投放/Sink/开关，不用活动当永久 Sink。
6. 默认熔断包含至少一档可回滚开关；无回滚不得入选。
7. 熔断副作用写回主环关键边，避免熔断制造新硬门。
8. 涉及产品表时：沙盒编辑走 excel-com-write，晋升另开 tunable-table-diff。

**做到**：熔断含触发与回滚；默认包已选定。

### 4. 写可复述结论

**做**
1. 汇总各情景是否过判据、选用熔断、残留风险。
2. 结论句格式：在情景 X 下若不启用熔断 Y，则在窗口 Z 触发判据 W。
3. 残留风险单列：接受理由或下游必跟动作（改价/改投放）。
4. 结论与情景参数一并归档，供版本评审口头复述。
5. 表变更晋升走 `tunable-table-diff`；结论不得声称「已热更」除非晋升完成。
6. 结论句与参数快照一并归档；复盘必须能复算。
7. 声称已热更前确认 tunable-table-diff 晋升完成。
8. 列出本步阻塞项 vs 可延后项；可延后必须写为何不挡本里程碑。

**做到**：结论句可口头复述；参数可复算。

下一步常接：改投放/价档后回扫 `sink-source-map` / `price-curve-pass`；表变更 `tunable-table-diff`。
