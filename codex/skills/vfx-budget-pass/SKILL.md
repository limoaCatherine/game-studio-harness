# 特效 Overdraw/粒子预算怎么控

## 何时用

- 要定或验收特效性能预算
- Overdraw/粒子爆炸掉帧
- 低端机特效不可玩
- 群怪/大招同屏超填色

## 怎么做

### 1. 订分档上限

1. 写 Overdraw、粒子数、同屏特效实例上限；每项写测量法（热区视图/计数器/帧分析）。
2. 对齐总性能帧切片；战斗可读优先于装饰。
3. 分画质档（低/中/高）各写一行上限；向用户索取档位数字，不编造。
4. 半透明层数与全屏后处理另计，不与粒子上限混成一句口号。
5. 群怪/大招场景单独标「峰值允许」与「日常允许」两档。
6. 预算表版本化，通知 `vfx-skill-hook` 默认遵守。
7. 测量时关闭无关后处理再拍热区，避免误把后处理算进特效 Overdraw。

**做到**：分画质档上限与测量法可复述。

### 2. 测热区

1. 定集火/大招/群怪代表场景；目标档录峰值与 Overdraw 热区图。
2. 半透明层叠处拍热区；粒子系统逐个开关二分定位超标源。
3. 列超标特效与触发条件（技能 id、人数、画质档）。
4. 编辑器数据只作初筛；补目标档或同等档设备数据后再定结论。
5. 记录测量工具与版本，保证他人能复测同一指标。
6. 打开帧分析确认超标是 fill 还是 CPU 粒子更新，对症治理。

**做到**：超标列表有证据（图/数）；来源可指；含目标档读数。

### 3. 做降级

1. 按优先级：先剔装饰、缩粒子、降半透明层数；命中闪白、受击方向、危险区预警保留到最后。
2. 写触发条件→降级动作→优先保留项；改完同场景复测峰值。
3. 低端机默认走降级档；允许玩家选项时写清默认值。
4. 降级后缩图/实机核：命中闪白、受击方向、危险区预警仍可读。
5. 超标未处理标债项（特效 id+条件+计划），预算落地以复测或债项为准。
6. 把降级表与预算上限放同一版本号下，避免挂接读到旧表。

**做到**：降级表可执行；复测峰值回预算内或债项显式；战斗可读仍在。

### 4. 固化供挂接遵守

1. 预算与降级表版本化；挂接新特效默认读此表。
2. `vfx-skill-hook` 开工检查：超上限须降配或申报后再挂。
3. CI 或人工抽测代表场景是否仍超；回弹则重开测热区。
4. 与 `perf-budget-check` 对齐特效切片口径。
5. 通知程序：限流/踢特效策略接口名与触发条件。
6. 归档热区图与峰值表，作为下次对比基线。

**做到**：`vfx-skill-hook` 可引用同一版本上限。

### 5. 代表场景固化回归

1. 把代表场景关卡名、画质档、测量步骤写成可复跑清单。
2. 每次大招/群怪内容更新后重跑热区；回弹则重开降级。
3. 限流策略与程序接口联调一次：触发时保留受击可读。
4. 归档热区图命名含日期与版本，便于对比。
5. 低端机实机至少一趟峰值；无设备则向用户索取同等档数据。
6. 预算版本写入 vfx 挂接表强制字段。

**做到**：复跑清单可用；挂接强制读版本；低端有数据。

## 做到

- 分档 Overdraw/粒子/同屏上限明确且可测；代表场景热区有证据
- 降级保战斗可读；复测有结果；超标已处置或债项显式
- 预算版本可供挂接遵守

## 失败回哪一步

- 档位数字空、测量法未写 → 回步骤 1
- 只有编辑器数据、超标源指不出 → 回步骤 2
- 降级关掉命中/受击信息、复测仍超且无债项 → 回步骤 3
- 挂接读到旧表、回弹 → 回步骤 4（必要时回 2）
- 低端无数据、复跑清单空 → 回步骤 5

下一步常接：`vfx-skill-hook`；总账 `perf-budget-check`。
## 加厚：Overdraw / 粒子预算实操信号

### A. 测量口径（与总性能切片对齐）

1. Overdraw：用引擎半透明/热区调试视图；记录「峰值色阶区域占屏比」与「单技能最长持续半透明层数」两数，不混成一句「有点红」。
2. 粒子：同屏活跃粒子数 + 发射器实例数分列；GPU 粒子与 CPU 粒子分开记账，避免限流踢错对象。
3. 填色 vs CPU：帧分析里若 VS/PS 占比高优先砍层数/面积；若粒子更新/模拟高优先砍发射率与生命周期。
4. 画质档：低/中/高三行上限；低端默认启用降级表，中高可选，默认值写进表。
5. 峰值场景：至少「单人大招」「小群（N 怪，N 向用户索取）」「Boss 多段」三类；缺一类不得宣称预算落地。
6. 关闭无关全屏后处理再测特效热区；后处理单独进 `shader-budget-note` / 总账，不吃特效预算。

### B. 降级优先级与可读底线

1. 先剔装饰拖尾/环境雾点，再缩发射率，再降半透明层，最后才动命中闪白、受击方向箭头、地面危险区预警。
2. 每条降级写：触发条件（画质档/同屏实例/机型）→ 动作（关哪个系统/调哪个参数）→ 保留项清单。
3. 降级后必须缩图或实机核：受击方向仍可指、危险区边缘仍可辨；失败则该降级方案作废重写。
4. 限流接口名与程序对齐；触发时日志打出被踢特效 id，便于回放。
5. 预算版本号成为 `vfx-skill-hook` 强制字段；缺版本拒挂。

**工具类别**：引擎调试视图、帧分析器、粒子计数器、版本库中的预算表、CI 抽测任务。

## 工具锚点（live mcp.json）

- `renderdoc`：热区/Overdraw 捕获（先 tools/list + 人工框选）
- `gamedev-mcp`：粒子计数/画质档切换
- `ffmpeg`：对比录像切片
- `excelMCP`：预算/降级表版本化
- **DoD：** 分档上限表；热区图+峰值；降级后可读仍在。
