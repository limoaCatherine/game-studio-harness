# 灰盒怎么验尺度动线再交美术

## 何时用

- 新关/新区要先验证空间再美化
- 动线卡死、无回报死路、视野死角、垂直切片要跑通
- 关卡过大要先缩体块

## 怎么做

### 1. 锁尺度与模块基准

1. 对照关卡目标与角色碰撞体，写清门高、走廊宽、跳跃高差、掩体高度等**尺度表**。
2. 统一网格步长与枢轴；模块边长可拼，禁止随意缩放破坏模数。
3. 放入角色/相机代理，站姿与蹲姿各量一次通过净空。
4. 垂直层（楼梯/电梯/落差）标可达性与坠落致死区，与玩法意图一致。
5. 不可达装饰空间与可玩空间分层命名。
6. **尺度表进版本库**；改尺度须升版并通知关卡与美术。

**做到**：尺度表与模数约定已版本化；胶囊净空可测。

### 2. 铺动线与门控

1. 从出生点到目标画主/次动线；岔路与回头路色块区分。
2. **门控开启条件表**：钥匙门/过场门/战斗锁门 — 开启条件与失败回流可指。
3. 战斗遭遇区标进入触发体、撤离口、掩体密度；灰盒掩体用统一高度档。
4. 查卡死角：无出口凹室、不可翻越却视觉可过、单向跌落无回程。
5. 多人/单人路径若并存，分别标容量与阻塞宽度。
6. 动线变更记入关卡备注，附前后截图。

**做到**：主次动线与门控可指；无卡死角。

### 3. 视线与可读性实测

1. **玩家视角**沿主动线走一遍，记遮挡过强或空旷无锚点段落。
2. 关键目标（出口、敌人刷新、拾取）进入区时**剪影可读**；不可读则调高度/开口。
3. 光源代理只为可读性，不代替最终光影。
4. 远景板/天空盒占位确认地平线与导向色块不误导。
5. 截取关键拐角前后帧，标视线阻断原因。
6. 不合格回步骤 2 改开口/掩体；**禁止贴材质/高模掩盖**。

**做到**：关键目标剪影可读；问题段落有截图原因。

### 4. 玩家视角验收与交接美术

1. **完整通关灰盒一遍**：记卡关、误触触发、相机穿模。
2. 列出**分区美术替换清单**：优先级、模块 ID、保留灰盒碰撞与否。
3. 碰撞代理与可视网格关系写清：哪些面最终由美术网格承接碰撞。
4. 导航网格（若有）在灰盒上烘焙抽测，断导航标返工。
5. 交接包：尺度表、动线图、门控表、问题清单、通过截图。
6. 未通过分区禁止进入最终材质/高模替换队列。

**做到**：玩家通关记录在；分区交接清单可供 `environment-artist` / `env-asset-checklist` 替换。

## 做到

- [ ] 尺度表与模数约定已版本化
- [ ] 主次动线与门控可指且无卡死角
- [ ] 玩家视角通关灰盒一遍，关键目标剪影可读
- [ ] 分区交接清单可供环境美术替换

## 工具锚

- 引擎 `Assets/` 或 `Content/` 导入目录与机检日志
- 导出中间件 `.fbx` / 贴图与材质槽路径
- CI 或本地 `import` 机检脚本输出（缺依赖、DefaultMaterial、骨架）

## 失败回哪一步

- 尺度表未版本化、净空未量 → 回 1
- 卡死角、门控条件空 → 回 2
- 剪影不可读、用贴图掩盖 → 回 3（必要时回 2）
- 未通关、无分区清单却进高模 → 回 4

下一步常接：`env-asset-checklist`；气质参考 `style-anchor`。不写最终材质/光照配方与敌人数值。

工具锚：引擎关卡编辑器 · 碰撞/导航调试可视化 · 尺度对照表 · 版本库 · 截图备注
