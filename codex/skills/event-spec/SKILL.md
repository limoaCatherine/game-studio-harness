# 活动规格怎么写

## 何时用

- 新活动要可配置规格；奖励轨过肝/不公或与常驻进度冲突
- 成功指标与下线方案未定；付费墙边界需显式
- 活动故事与主时间线关系需声明

## 怎么做

### 1. 目标、受众、参与约束

**做**
1. 写目标句（留存/回收/主题叙事/赛季钩）+ 非目标；目标玩家分段槽（新/回/肝/付费）；挂支柱 ID。
2. 参与：入口 UI 键名、资格字段、日/周上限字段——在配置表或后台打开确认列存在（`event.xlsx` sheet.col / 运营后台）。
3. 文首写伦理底线：主轨核心免费可完成；付费只做便利/外观/加速。
4. 常驻冲突检查：对照 `sink-source-map` 与日常体力表，标是否抢同一 Sink/时间窗。
5. 叙事例外声明「不回写主圣经」；指针 `lore-consistency-check`；起止版本槽。
6. 向用户索取肝度档与付费档边界；无档不堆任务条数。
7. 失败→回本步：上限/资格字段在表中不存在——先建空槽列或改名再往下。

**做到**：规格文首有目标/非目标/付费墙底线；入口键与上限列可在表/后台点开；常驻冲突已标。

### 2. 核心循环与奖励轨（表字段）

**做**
1. 画循环：行为→进度→奖励；每环写字段名（`score_counter`/`token_id`/`milestone_tier`）。
2. 奖励轨表列：免费轨、付费轨、里程碑、限时货币、掉率、保底——掉率与保底写入表列。
3. 玩法向关键奖励（进度解锁/关键材料）至少一条在免费轨可达成；用表行号标注。
4. Source/Sink 登记产销地图指针；与常驻 Source 叠加写帽字段（`cap_daily`/`cap_event`）。
5. 任务步进若用 `quest-spec`：每日重置、补领、去重键与邮件模板 id 一致；防双领。
6. 给轻/标准 2 套强度及对留存/收入利弊；用户选定后冻结表版本号。
7. 产品表编辑走 `excel-com-write` 沙盒路径。
8. 失败→回步骤 1：关键奖励仅付费或掉率列缺失——改轨/补列后再冻版本。

**做到**：循环字段可配置；掉率与保底列可见；经济指针与帽字段齐全；强度档+表版本冻结。

### 3. 指标、开关、日历、上下线

**做**
1. 成功指标写埋点事件名（参与/完成/付费转化）与看板查询路径；熔断条件写阈值槽（事故、差评、经济失控）。
2. 上线清单：配置开关名、公告键、邮件 id、商店 SKU、客服话术、埋点——预发环境实际切换开关，确认入口显隐。
3. 下线遗留：货币/道具/进度/邮件附件处理规则；过期补偿是否配置（`reward-mail-check`）。
4. 打开 `liveops-calendar`：开启/冻结/公告日必须与规格同一行日期；冲突则改其一。
5. 风险条目挂 `risk-register-update`（经济爆炸、开关失效、预告过度）含早期信号。
6. 写可离线预演路径：接取→领奖→下线残留；故障处置槽：禁用/延长/补偿。
7. 失败→回步骤 2：开关名与文档不一致，或日历日冲突——统一名称/日期再预演。

**做到**：埋点名可查；预发开关切换有记录；日历日一致；遗留与熔断可执行。

### 4. 验收与登记

**做**
1. 验收证据钉死：配置可点开（开关/奖励轨/上限列）、埋点名可检索、失败补发用例在沙盒通过（去重键+补发模板）。
2. 开放问题列表交用户：未决资格/强度/日历冲突。
3. 规格路径走产物登记；常接表格写入配方与活服日历对齐。
4. 抽检：开关一切一显/一切一隐；补发跑一条沙盒并记 PASS/FAIL。
5. 不合格回对应步补字段：缺补发键→回步骤 3；缺目标/付费墙→回步骤 1；缺免费关键奖励→回步骤 2。
6. 预告变更口径指针 `release-notes-stub`；不在本步写 UX 长文或复盘散文。

**做到**：配置槽与验收证据可指；补发用例通过；规格已登记；开放问题已列。

下一步常接：`artifacts-append`；`release-notes-stub`；表格写入与活服日历对齐。
