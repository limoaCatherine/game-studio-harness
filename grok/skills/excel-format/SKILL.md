# 格式层

只改样子，不改存值。写表技能做完内容后**必须**交本层，排本轮改过的区。只读走 `excel-read`，改值 / 插行走 `excel-com-write`。

工具：先 `xlsx_probe` + `xlsx_sandbox_clone`（只落到正式表同级 `沙箱/`），只排该副本。沙箱不进 git，见 `write-isolation`。能 COM 用 `range_format` 一次传齐 font / fill / align。否则 `xlsx_format_range` **只传要改的键**，禁止默认 `bold=false`。行高列宽用对应工具。做完 `xlsx_release`。本轮要给人审：只对沙箱 `file open show=true`，禁止开正式簿。审阅完（人已准晋升、接着说话且不再看窗、或明确说合/关/继续）当拍 `xlsx_release keep_visible=false`，不要问「还开着看吗」。工具表没有 `xlsx_release`：关审阅会话和隐藏会话，再 diagnose；无可见审阅窗则 reap。释放指 COM，不是删沙箱文件。

每格先答四问，再动笔。只套命中的那一套，不要把三种表的装饰叠到同一块。

| 问 | 判什么 |
|---|---|
| 管多大 | L0 表名 / L1 节 / L2 子节 / L3 列头 / 其余数据 |
| 这一列是什么 | 标签、枚举、说明、单位、数字、间隔 |
| 哪种量 | 序号整数，其余数字六位；真零显示 0，未配才是 `—` |
| 要多少空间 | 按列角色夹列宽；溢出才换行，再给行高 |

先认这一块怎么分段，再决定切线。有「类型」列不等于都要画组界。

| 表 | 怎么认 | 怎么隔开 |
|---|---|---|
| 关系 / 公式 | 同行 ≥2 个 L1，或块内已有 L2 小段 | 只靠 L1 底色与空列，不画组界 |
| 目录 | 一段里连续记录、一行一条；分类靠某一列 | 该列值变了 = 组界细线；不插空行 |
| 参数 | 名称 + 录入 + 公式，无左右分块 | 录入蓝、公式黑；可调黄盒 |

格子独立：文字落在起始格；通栏用该层底色铺已用列；不冻窗格；已有合并拆开，值留左上。关网格线。全簿一种字体（已统一则跟簿，否则微软雅黑 / Calibri 10）。

## 1. 管多大

| 级 | 字 | 底 |
|---|---|---|
| L0 表名 | `#1F4E79` 粗 14–16 左 | `#F2F2F2` 铺已用列 |
| L1 节 | `#1F4E79` 粗 12 左 | `#E7E6E6` 铺该组列 |
| L2 子节 | `#404040` 粗 10 左 | `#F2F2F2` 只盖标题格 |
| L3 列头 | `#404040` 粗 10 左、垂直中 | `#D9D9D9` 有字段的格 |
| 数据 | 跟列角色 | 白 |
| 可调 / 假设 | `#0000FF` | `#FFFF99` + 灰框 |

目录块：分组键变了，新组首行顶 `thin` `#000000`，第一组不划。关系 / 小段不画。间隔列空、底白。

## 2. 这一列是什么

按序命中即停：标签 / ID（名称、序号、编号、主键）→ 枚举 / 开关 → 说明 / 公式原文 → 单位 → 数字 → 间隔。

能读成数的文本按格左对齐、垂直居中、按下表上色，不改存值。

| 条件 | 字 | 底 |
|---|---|---|
| 空或仅 `—` | `#808080` | 白 |
| 标签 / 枚举 / 说明 | `#000000` | 白 |
| 可调参数、假设 | `#0000FF` | `#FFFF99` |
| 无 `=` 的数、或公式整个是一个数 | `#0000FF` | 白 |
| 公式含 `[` | `#FF0000` | 白 |
| 公式含 `!` | `#008000` | 白 |
| 其余有引用的公式 | `#000000` | 白 |

有引用的公式不铺黄。黄盒只给可调 / 假设。

## 3. 哪种量

| 类 | 格式串 |
|---|---|
| 序号类 | `0` |
| 默认数字 | `0.000000;-0.000000;0.000000` |

序号类：字段名是序号 / 步骤 / 编号 / 行号 / 帧 / 毫秒 / ID；或列角色已是标签 / ID 且存整数；或从首条数据起多数格是连续整数。其余数字一律六位，零也是 `0.000000`。真零存 `0`；未配存 `—`。禁止第三段写成 `"-"`，禁止擅自改 `%` / 千分位 / 少位数。

凡数、公式、能读成数的文本、标签：水平左、垂直中。

## 4. 要多少空间

| 对象 | 下限 | 上限 |
|---|---|---|
| 间隔列 | 2 | 4 |
| 数字列 | 8 | 14 |
| 单位列 | 6 | 10 |
| 标签 / 枚举列 | 8 | 24 |
| 说明 / 公式原文列 | 12 | 36 |

列宽 = 已用格字宽 + 边距，夹进上下限。同 L1 同角色数字列取齐。仍超上限：只给溢出格换行，列宽钉在上限，行高 `字号×1.35×行数 + 4`（下限 15），直到整段可见。

## 落到格子

1. 预检样式。认三种表，只走命中的那条。
2. 一次传齐 font / fill / align；线先清再画目录组界或假设框。
3. 数字格式按第 3 节。保持原行数、原值、原公式。
4. 量宽 → 夹限 → 溢出换行 → 给行高。
5. 拆合并，不冻窗格。
