# 经济循环怎么拆与怎么改

## 何时用

- 要设计或重做核心行为→奖励→强化→再行为环
- 循环「玩不动 / 囤积 / 卡死」需要定位断在哪
- 活动或付费点要插进主环，需先看清边
- 需要与 sink-source 对齐的环图

## 怎么做

### 1. 拆节点（行为→奖励→强化→再行为）

**做**
1. 沿玩家主路径列出节点；每节点写：触发条件、消耗什么、产出什么、对应表主键（没有就标空槽名）。
2. 节点用动词短语命名（如「清日常」「强化装备」）。
3. 主环只留行为→奖励→强化→再行为四类；交易/邮件/活动/GM/补偿标旁路另编号。
4. 对每个节点问：缺输入时玩家做什么？无答案标「硬门风险」；有答案记下退化去向节点。
5. 声明循环边界：哪些货币/材料/行为进本环、哪些只作旁路输入；成功标准写成可观测滞留/断裂点名。
6. 输出节点表：名、类型、触发、消耗、产出、表主键、硬门?。

**做到**：主环节点列表完整；旁路不混编号；硬门风险可见。

### 2. 画有向边与付费/退化

**做**
1. 相邻节点连有向边；每边写：触发事件、代价、奖励、冷却/次数上限字段、表来源 sheet.col。
2. 边缺表来源则标空槽名。
3. 在痛点边上标注可选付费插入类型（跳过冷却/补资源/加速），只标位置与类型，不定价故事。
4. 从每个失败/耗尽态画退化边回安全行为；画不出的记硬门表。
5. 标注冷却与投放频率字段是否同单位（日/周/局）；单位不一致先统一再往下。
6. 输出边表与环草图：从、到、触发、代价、奖励、表来源、旁路?、付费插入?。

**做到**：每条主环边有表来源或空槽；硬门与付费插入显式。

### 3. 找断裂、滞留与关键边

**做**
1. 对每个节点写三态：输入不足样子、产出溢出样子、正常稳态；各配一个可观测指标名（计数器/日志，不编数）。
2. 逐边做「去掉这条边后主环还有没有出路」——没有出路的记关键边，并写当前缓解是否存在。
3. 对照冷却与投放频率，标玩家容易超窗停住的节点，写「为何停」假设（缺资源/门槛/无目标）。
4. 对每个断裂/滞留点给 2～3 修法：改投放字段 / 改代价 / 开旁路 / 硬门改软门；各写利弊与影响面。
5. 先修关键边再调投放量。
6. 输出诊断表：节点/边、断裂或滞留样子、指标槽、修法选项。

**做到**：断裂点、滞留点、关键边列表可指着讨论。

### 4. 决定改什么并冻结

**做**
1. 用户选定修法后，映射到具体 sheet/列清单；产品表改动走 `excel-com-write`（沙盒→`tunable-table-diff` 晋升）。
2. 本版冻结：环拓扑与关键边结构；可继续拧的只有约定数值字段——分栏写清。
3. 付费插入仅保留选定位置类型，定价交给 price-curve / iap；付费插入只标位置类型，定价交 price-curve / iap。
4. 输出环图+诊断+改表清单，供 sink-source-map / price-curve-pass / inflation-stress 引用。
5. 变更后重跑关键边检测：修法不得制造新硬门无退化。

**做到**：修法已落到字段名；冻结边界写清；下游可引用。

## 失败回哪一步

- 节点命名空泛或旁路混进主环 → 回步骤 1
- 边缺表来源/硬门无退化 → 回步骤 2
- 关键边或滞留点无修法选项 → 回步骤 3
- 修法未落到 sheet.col 或制造新硬门 → 回步骤 4 后重跑关键边检测

下一步常接：`sink-source-map` / `price-curve-pass` / `inflation-stress`；改表晋升 `tunable-table-diff`。
