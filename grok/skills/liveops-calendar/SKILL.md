# 活服日历怎么排

## 何时用

- 新赛季/季度要排期，或活动重叠导致玩家/产能过载
- 经济重置点需对齐公告与配置冻结
- 要给各职种冻结日程与内容缓冲
- 大战峰值间隔不清，商店轮换撞车

## 怎么做

### 1. 定节奏骨架与产能上限

1. 写赛季时长与主题槽；切钩子期/稳定期/收束期。
2. 经济重置点：限时货币是否过期、通行证是否重置、公告提前量档——写入里程碑。
3. 产能上限：可并行活动槽、大战峰值最小间隔、周常/日常负担上限（向制作方索取）。
4. cadence 层：日/周/月/赛季——每层典型内容类型+缓冲。
5. 叙事主题预算对照 beat/活动故事产能；无产能则降主题承诺。
6. 冻 skeleton_version；改赛季长度须升版本。
7. 不合格：产能档空或重置日两套时间 → 统一后再填事件。

**做到**：skeleton_version 冻结；重置里程碑与产能上限可见；日/周/季层有缓冲。

### 2. 填事件并扫描重叠

1. 事件表字段：name、type、start、end、deps、reward_channel、owner、event_spec_id。
2. 同屏负担扫描：玩法时间/肝度/付费点密度；冲突给错峰/降强度/合并选项。
3. Source 叠加检查同货币同时发放；有则错峰或改 Sink，挂经济指针。
4. 商店轮换与礼包：预告期与上架期不得无声重叠；核 SKU 窗。
5. 预留应急空窗；无规格事件不得钉死开启日。
6. 不合格：峰值间隔小于最小间隔 → 先改骨架再改起止。

**做到**：事件表与日历块对应；硬冲突有选型；无规格未钉开启日；应急槽≥1。

### 3. 锁冻结日、公告与指标

1. 写配置冻结日、公告日、上架日、开启日链路；责任人可指。
2. 埋点与 KPI 口径指针对齐 monetization-kpi-pass；缺事件名标阻塞。
3. 维护窗与时区写入；跨区开启差写清。
4. 备档活动与取消条件可见；取消不留幽灵入口。
5. 与商业化周期错峰选项记录决策。
6. 不合格：冻结链路缺责任人或时区空 → 回补后再锁。

**做到**：冻结/公告/开启链路与责任人可指；时区与维护窗写入；KPI 指针齐全。

### 4. 漂移、熔断与复盘

1. 漂移监测：延期/加赛须评审；冻结日后加塞要升级。
2. 熔断：事故停开/缩奖/补发预案一页；演练记录时间。
3. 复盘一行回写日历：实际负担 vs 产能上限。
4. 输出日历版本、冲突消解记录、应急槽列表。
5. 入库文档仓；配置 diff 与回滚执行人写清。
6. 不合格：无熔断预案或复盘空 → 补一页再标可开季。

**做到**：熔断预案与复盘可检索；日历版本与冲突消解记录入库。

## 做到

- 骨架版本冻结且重置里程碑可见
- 事件表与日历块一一对应；硬冲突有选型记录
- 无规格事件未钉死开启日；应急槽≥1
- 冻结/公告/开启链路与熔断预案可检索

## 失败回哪一步

- 步骤1（定节奏骨架与产能上限）：产能档空或重置日两套时间 → 统一后再填事件。
- 步骤2（填事件并扫描重叠）：峰值间隔小于最小间隔 → 先改骨架再改起止。
- 步骤3（锁冻结日、公告与指标）：冻结链路缺责任人或时区空 → 回补后再锁。
- 步骤4（漂移、熔断与复盘）：无熔断预案或复盘空 → 补一页再标可开季。

下一步常接：`liveops-designer`；`reward-mail-check`；`iap-catalog-check`；`monetization-kpi-pass`；`narrative-beat-sheet`。

## 工具锚

- 运营日历 / 商品目录表 `.xlsx`
- KPI 看板导出或快照 `.json` / `.md`
- 变更记录落入 `.harness/artifacts/`

## 不在本文件

- 活动玩法规则全文（应交 event-spec）
- 经济通胀主模型
- 服务器发放实现
- 战斗数值
