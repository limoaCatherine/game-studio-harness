# 动画集怎么列齐与收包

## 何时用

- 角色/怪物要定可玩动作边界再开动画
- Locomotion 或缺受击/死亡导致无法竖切
- 技能槽与片段一对不齐；外包回传要按同一清单收口

## 勾选主路径

### 1. 从能力与槽位推导动作清单

- [ ] 对照能力说明/技能槽/行为简述拆出 anim_id（禁止凭空开表）
- [ ] 每条写：用途、循环、根运动、混合优先级、技能槽（无槽标系统/氛围）、是否最小可玩
- [ ] 最小可玩四类齐：移动（idle+走/跑）、交互或攻击、受击、死亡/失败；缺一类=阻塞
- [ ] 完整集另栏（起停/转向/空中/轻重受击/技能全套），与最小可玩分栏
- [ ] 与技能槽一对一勾选；共用片段写明；占位写清可竖切/不可当正片
- [ ] 方向数/帧率/镜像未给定则索取后再锁表

### 2. 核对仓库片段存在与切分名

- [ ] 每 anim_id 标 存在/缺失/占位；最小可玩缺失=阻塞
- [ ] 打开片段核对切分名、时长、帧率与 anim_id 一致
- [ ] 无空片段/0 时长/裸 T-Pose 进正式包（用项目约定占位）
- [ ] 同名冲突进冲突表并定保留源
- [ ] 外包对照清单勾交付；多余进 Orphan，不自动升正片
- [ ] 缺口表按责任分列，阻塞置顶，可按 anim_id 检索

### 3. 统一技术约束并抽测

- [ ] 集表头写死：帧率、原地 vs 根运动职责、镜像、压缩档、循环首尾对齐
- [ ] 同一段移动只由根运动或程序位移一方驱动；试玩无脚滑/双计
- [ ] 受击/死亡时长与取消窗对照状态机可接
- [ ] Locomotion 方向矩阵齐或显式本版减向；缺转身/起停写清程序扭或硬切
- [ ] 引擎抽测：循环脚滑、落地滑动、攻击恢复可打断——**通过记录可指**
- [ ] 压缩预览无不可接受手抖（调档或保护关键骨曲线）

### 4. 收包并交接事件挂点

- [ ] 收包文件集：路径 + anim_id + 版本号
- [ ] 占位转正条件/责任人写清；未转正不当正片
- [ ] 通知下游可挂事件（优先攻击命中/脚步片段列表）→ `anim-event-hook`
- [ ] 装配冒烟：能走、能打或能交互一趟
- [ ] 完整集未齐进排期，不与最小可玩混称做完
- [ ] 表与磁盘路径再对一次名

## 做到

- [ ] 最小可玩四类齐全或阻塞已显式列出
- [ ] anim_id 与技能槽/系统用途对齐；片段存在性与切分名已核对
- [ ] 集表头技术约束统一；**抽测脚滑/取消窗有通过记录**
- [ ] 收包文件集含路径+anim_id+版本，可被事件挂点引用

## 工具锚

- 骨架 / 蒙皮资产路径（`Assets/` 或 `Content/`）与绑定检查清单
- 动画 Clip / 状态机引用扫描日志
- DCC 导出 `.fbx` 与引擎重定向表

## 失败回哪一步

- 凭空 anim_id / 缺四类 → 回 1
- 假齐、clip 名漂、裸 T-Pose → 回 2
- 根运动双计、脚滑、取消窗接不上 → 回 3
- 冒烟不过、占位当正片、表盘不一致 → 回 3 后再收包

下一步常接：`anim-event-hook`。不写事件 Notify 全文与伤害公式。

工具锚：DCC 动画时间轴 · 引擎动画资源浏览器 · 版本库路径 diff · 状态机试播 · 命名规范表
