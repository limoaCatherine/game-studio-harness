# 奖励邮件怎么核对

## 何时用

- 版本补偿/活动发奖前要过安全与字段核
- 邮件多领/漏领事故后复盘
- 限时奖励过期规则不清
- GM/客服补发通道需 ACL 约束，或邮件成隐蔽 Source

## 怎么做

### 1. 枚举通道与权限

1. 列通道：系统事件/补偿/GM/客服工具/订阅等；每通道填 channel_id、权限角色、审批字段、白名单引用、Source_id。
2. 对读实际工具权限配置：能发但无审批→红灯；关掉绕过或加审批。
3. 可邮寄物品白名单/黑名单路径写清；高价值货币额外审批位必开。
4. 邮件 Source 必须在经济通道图有登记；缺失两边补。
5. 白名单变更走同一审批字段。
6. 不合格：红灯通道未处置 → 停发先修权限。

**做到**：每通道有权限+审批+白名单+Source_id；红灯已处置。

### 2. 单封字段与去重键

1. 每封核：mail_id、收件条件、item_id×qty、绑定、mail_expire、item_expire、可手删、已读策略。
2. 去重键覆盖补偿事件 id + 角色/账号级；键字段名写入配置表。
3. 演练同一补偿发两次：第二次须拒领或合并；日志关键字可搜。
4. 数量与活动配置/公告一致；邮件过期与物品过期分列。
5. 附件为空仍占位或可转绑高价值→记失败项；无去重键阻断群发。
6. 不合格：去重演练失败 → 回补键再发。

**做到**：去重键可演练且日志可搜；过期字段分列无歧义。

### 3. 审计日志与滥用扫描

1. 审计日志可按操作者过滤：operator、time、channel_id、mail_id、qty_summary、approve_id。
2. 扫风险：无去重、可转绑高价值、过期后仍可领、空附件、批量 GM 无审计。
3. 补发条件与人工工单路径写清；不可补发项提前标红升裁。
4. 多语言模板槽位；文案键走 copy-pass。
5. 与活动规格/日历交叉：过期态入口不得幽灵可领。
6. 不合格：无审计或过期仍可领 → 回改模板/通道。

**做到**：审计可按操作者过滤；滥用项已处置或升裁。

### 4. 沙盒发送与可发送集

1. 沙盒：开/中/关/补发四路径演练；白名单测试角色。
2. 输出可发送集 + 阻断清单 + 补发手册一页。
3. 回滚与停发执行人；事故预案指针。
4. 入库文档仓；配置版本与表 diff。
5. 交接客服/程序：去重键名、日志关键字、审批位。
6. 不合格：四路径未过 → 不进可发送集。

**做到**：沙盒开/中/关/补发四路径通过；可发送集与阻断清单分明。

## 做到

- 每通道有权限+审批+白名单+Source_id
- 去重键演练可搜日志；过期字段无歧义
- 审计可按操作者过滤；滥用项已处置或升裁
- 沙盒四路径通过并形成可发送集

## 失败回哪一步

- 步骤1（枚举通道与权限）：红灯通道未处置 → 停发先修权限。
- 步骤2（单封字段与去重键）：去重演练失败 → 回补键再发。
- 步骤3（审计日志与滥用扫描）：无审计或过期仍可领 → 回改模板/通道。
- 步骤4（沙盒发送与可发送集）：四路径未过 → 不进可发送集。
