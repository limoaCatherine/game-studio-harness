# 任务规格怎么写

## 何时用

- 新主线/支线/日常/隐式任务要落可实现规格
- 目标链断裂、步骤不可检测或口头目标过多
- 奖励通道与经济冲突，或分支/失败/放弃规则不清
- 要给程序的状态机与存档字段名

## 怎么做

### 1. 定类型、叙事锚与目标链

**做**
1. 定类型：主线/支线/日常/周常/隐式成就；写任务 id 与显示名（显示名可走 `copy-pass`，id 稳定）。
2. 对齐叙事 beat 与关卡目标：本任务推进哪一拍/哪一关；写一句「玩家以为自己在做什么」。
3. 写主目标链：每步用可检测完成条件（事件名/计数器/到达触发/持有物/击杀）。
4. 可选步与强制步分开编号；可选失败不得阻塞主链；并行步写汇合条件。
5. 每步写指引文案键槽与地图标记策略（有/无）；无标记的步骤必须有替代空间线索或 NPC 提示。
6. 向用户确认日常重置时区与补领规则档；无则索取，不填默认时刻。

**做到**：类型与叙事锚已写；目标链每步有检测器名或事件槽；可选/强制分离；指引策略可见；失败→回本步 改 检测器名或目标链步骤

### 2. 触发、状态机、失败与放弃

**做**
1. 写接取条件（等级/前置任务/区域/物品）、步进条件、完成条件；互斥任务与冷却字段显式。
2. 画状态机：未接→进行中→完成/失败/放弃（按项目裁剪）；每转换写合法事件；非法转换写拒绝策略（忽略/提示）。
3. 状态名与存档字段名对齐；需要持久的世界后果（NPC 敌对、门开）用独立旗帜，不塞进临时任务局部变量却指望过天仍在。
4. 放弃/失败后的世界回滚规则显式：半完成道具、NPC 旗、区域锁、计数器；关键道具不可因放弃而丢尽导致软锁。
5. 列出至少三条软锁检查：无钥匙循环、唯一道具可丢、战斗门无退化——有则改设计或补退化路径。
6. 重接规则：失败后可否重接、进度是否保留；与对白重谈规则交叉，避免「对白已选但任务回滚」不一致。

**做到**：状态转换表可实现；回滚与防软锁规则可见；存档字段可指；重接策略清楚；失败→回步骤 1 改 目标链/检测器或状态名

### 3. 奖励、经济与副作用

**做**
1. 列奖励：物品/资源/解锁/外观；标直发或邮件；大额 Source 记 `sink-source-map` 通道指针。
2. 日常/周常写重置时区、补领规则与去重键；补领与 `reward-mail-check` 去重交叉，防双领。
3. 分支互斥用状态标志，不靠对白选项隐式互斥；互斥表与 `dialogue-pass` 后果字段同名。
4. 失败惩罚若有：写清扣什么、是否可防、是否影响付费道具。
5. 隐式成就类：触发条件可检测且可向玩家解释。

**做到**：奖励通道与经济指针齐全；重置/补领无双领漏洞描述；互斥显式；失败→回步骤 2 改 存档字段或奖励通道

### 4. 可玩验收路径

**做**
1. 写最小验收路径：接取→每强制步→领奖；旁注预期检测器触发点。
2. 写放弃路径与失败路径各一条；确认回滚后世界可继续玩。
3. 若依赖关卡/遭遇：引用 `level-goals-spec` / `encounter-script` id；缺下游则标阻塞，不假装任务可独立完成。
4. 产品表落盘走 `excel-com-write`；字段名与状态机一致。
5. 输出规格：目标链、状态机、奖励、软锁检查结果、验收路径；未决检测器名标红。

**做到**：成功/放弃/失败三路径可走查；下游依赖显式；表字段与文档一致；失败→回步骤 3 改 奖励/互斥或状态转换

下一步常接：文案 `dialogue-pass` / `copy-pass`；经济 `reward-mail-check`；遭遇 `encounter-script`。

## 细则

### A. 任务规格字段
1. `quest_id|title_key|desc_key|states|objectives|rewards|fail|reset|beat_id|loc_notes`。
2. 状态机至少：未接→进行→完成/失败；子目标若有则独立状态。
3. 目标键与关卡触发/物品/击杀计数器字段名对齐；禁止只写中文描述。
4. 奖励写类型与发放通道（直接/邮件）；数值槽可空但类型不可空。
5. 失败与回滚：放弃、断线、进度脏写如何恢复。

### B. 依赖与反作弊意识
1. 前置任务/世界状态列表；环状前置禁止。
2. 权威侧：关键进度以服务器或主机为准时在规格注明。
3. UI：任务追踪器条目与目标键一一对应。
4. 与对话开始/结束钩子事件名写死。
5. 失败→回 beat 表：无 beat_id 的主线任务需补挂或标支线。

### C. 验收
1. 新建任务在开发档用控制台/调试指令走完状态迁移。
2. 本地化键全部存在于文案表；缺键阻塞。
3. 自动化或手测清单：接取、更新、完成、放弃、重登恢复。
4. 信号：完成时奖励双发或未发——查发放通道。
5. 工具：任务编辑器/表、对话中间件、日志键。
