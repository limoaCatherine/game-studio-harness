# 动画事件挂点

## 何时用

- 攻击/受击/脚步要挂 Hit、Foot、SFX 事件
- 事件名各职种各叫一套，联调对不上
- 关键帧漂移，出伤窗与动画不同步
- 打断后仍误触发表现事件

## 怎么做

### 1. 建事件字典

1. 打开本里程碑技能槽表、动画片段清单与（若有）旧事件表；列出候选名（如 Hit_Primary、Foot_L、SFX_Swing、VFX_Cast）。
2. 对每条写：载荷字段（无则写「空」）、拥有方（动画/程序/特效/音频）、属表现事件还是权威结算入口；Hit 类默认只驱动表现/客户端预测。
3. 全文搜同义异名（Hit/HitFrame/OnHit/DamageFrame）；合并为唯一正式名，旧名写入「废弃别名→新名」，只保留一套正式名。
4. 与 skill-kit/表主键对齐：事件能指到技能槽或系统用途；指不到的标「系统/氛围」并写清监听方。
5. 字典落到可共享表或任务备注；缺载荷/命名风格向用户索取项目约定。表写入走表格写入配方（`excel-com-write`）若用 xlsx。
6. 显式分栏「表现|结算」：最终伤害以服务器结算为准；AnimNotify 只作表现/预测钩子，不写成权威伤害源。

**做到**：字典可口头复述；无野名与同义异名；表现与结算分栏清楚。

### 2. 在片段上植入关键帧

1. 按优先动作打开片段（DCC 或引擎 Animation 窗口）；在出伤峰值、着地、刃面接触、施法释放、脚步触地帧插入 Notify/Event。
2. 每条记录 anim_id / 事件名 / 帧号或归一化时间 / 片段版本；片段一改就重读帧号，以记录为准。
3. 字典没有的名字先补字典再插；临时名（Hit_tmp、event1）先升正式名再入库。
4. 循环片段写清首尾是否抑制双触发、左右脚是否交替；用循环预览查漏触发或一帧两响。
5. 多段攻击：每段独立事件名或带段号载荷；确认监听方能区分段。
6. 保存并导出含事件片段；确认 Notify 列表随文件进库；路径写回引用表。

**做到**：约定动作都有帧记录；帧号可回查；无无名事件；循环规则写清。

### 3. 联调听看打

1. 同屏播：开伤害窗调试线或结算日志、SFX、VFX；核对是否同帧；偏早/偏晚/丢失记入偏帧表（anim_id+事件+偏差方向+版本）。
2. 跑打断、受击取消、技能取消、死亡：表现事件在取消后应停；若仍触发，查不可取消轨道或未 Kill 监听。
3. 音频与 VFX 共用同一事件名、不同监听；同帧打同一正式名，不拆成 SFX_Hit/VFX_Hit 异名异帧。
4. 慢放或逐帧核对接触帧；长期靠逻辑垫 N 帧的，改回事件帧或改动画，以事件帧为正式方案。
5. 镜像与左右武器：核对 Foot_L/R 等在镜像后是否正确，或文档写明由程序映射。
6. 失败项回改帧或改字典；表现不同步时改帧/字典，不在玩法逻辑吞事件凑合。

**做到**：偏帧列表可指且已处理；打断无误触发；共用名已落实。

### 4. 改帧规则落地

1. 声明谁可改事件帧、哪些改后必须重联调（默认一切 Hit/Foot/技能释放帧必须重联调）。
2. 含事件片段路径写回引用表；旧路径标废弃；程序与特效只引新路径。
3. 字典改名时全局搜索替换监听代码/蓝图/文档；残留旧名扫到为零。
4. 保留帧号变更日志：旧帧→新帧→原因→是否已重联调。
5. 与 `vfx-skill-hook`、`client-combat-frame-debug` 对齐同一字典版本号。
6. 抽测至少一条攻击+一条脚步+一条取消路径作改帧后冒烟。

**做到**：改帧责任与重联调条件可见；路径可被下游引用；字典版本一致。

## 做到

- 事件字典无同义异名；表现/结算分栏清楚
- 约定动作均有 anim_id+事件+帧 记录
- 联调：出伤/SFX/VFX 对齐；打断无误触发；Hit 表现不冒充权威结算
- 含事件片段路径可被程序/特效引用

## 失败回哪一步

- 同义异名并存、表现结算糊 → 回步骤 1
- 帧号无记录、临时名进库 → 回步骤 2（无名先回 1 补字典）
- 偏帧、打断误触发、硬延时凑合 → 回步骤 3（改帧或回 2）
- 改帧未重联调、旧名残留 → 回步骤 4 并重跑步骤 3 冒烟

下一步常接：`vfx-skill-hook` / `client-combat-frame-debug`。
## 事件字典与帧权威

### A. 命名与分栏

1. 事件名稳定英文标识（如 `Hit`/`Foot_L`/`CastStart`）；禁止同义异名（Hit/Damage/Impact 并存）。
2. 表分栏：表现用（SFX/VFX）与结算用（伤害窗口）分列；Hit 表现事件不得被当成权威结算唯一来源，除非项目明文。
3. 帧记录：`anim_id + event_name + frame + 可选 duration`；改帧写日志旧→新→原因→是否重联调。
4. Notify 类事件绑 Socket 名与挂点表一致；缺 Socket 先补绑再挂特效。
5. 分支点/立即事件仅用于必须当帧响应的逻辑；普通表现用可排队事件，避免滥用立即事件打爆时序。

### B. 联调信号

1. 慢放：出伤闪白、受击反应、脚步与接触帧对齐；长期「逻辑垫 N 帧」改为改事件帧或改动画。
2. 打断/取消：取消窗内不得误触发已取消招的 Hit；用例至少一条写入冒烟。
3. 与 `vfx-skill-hook` 同一字典版本；特效挂接表强制填事件名+帧。
4. 镜像后 Foot_L/R 校验或程序映射文档三选一落地，禁止沉默错误。

**不合格回**：异名→步骤1；无帧记录→步骤2；偏帧/误触发→步骤3；改帧未重联调→步骤4。
