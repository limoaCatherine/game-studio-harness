# 设定一致性怎么查

## 何时用

- 新设定写入前验冲突，或对白/任务/物品描述与设定打架
- 多文档漂移、活动故事疑似破主时间线、人物关系双说法
- 入库前要标 canon 级别（Established / Provisional / Under Review）

## 怎么做

### 1. 锁权威源、索引与本检范围

**做**
1. 列出设定源路径与优先级（故事圣经 > 角色卡 > 任务文本 > 活动例外——以用户项目为准）；写入 `design/narrative/SOURCE_PRIORITY.md` 或任务备注。
2. 建/更新 **实体索引表**（sheet 或 `lore/index.csv`）：列 = entity_id、类型（人/地/势力/事件/规则）、canon 级、权威路径、别名。
3. 用 `rg -n "TODO|TBD|\[待定\]|矛盾" design/narrative` 标已知空洞；本检范围写清章节/活动/文案键集，超出只记指针。
4. 向用户确认活动例外政策：允许临时改规则时必须声明「不回写主圣经」；裁断人角色写死。
5. 打开待检文本清单（对白键、任务、物品、UI 传说、活动文案）及路径；用 `git log --oneline -- design/narrative` 看近期漂移提交。
6. 失败→回本步：无实体索引或权威优先级争执未裁——先补索引/请用户裁优先级，再扫正文。

**做到**：优先级文件可引用；实体索引含 id+canon+路径；待检清单与范围边界写死；裁断人明确。

### 2. 检索扫描并分类冲突

**做**
1. 对索引中每人名/地名/称号跑 `rg -n "Name|别名" design/ content/ locales/`（按项目根）；命中写入比对缓冲。
2. 能力规则对照「不可能」清单（世界规则文档）；破例必须已有登记条目或代价字段，否则标真冲突。
3. 时间线：按事件 id 排序检查因果倒置、死人再现无说明；工具面=时间线表 `event_id|date_slot|cause_of|authority`。
4. 每条记录：双方摘要、出处路径:行号、entity_id、分类（真冲突 / 源过时 / unverifiable / 语气差）。
5. 神秘设定：若项目要求真相应文档化，查 `true_answer` 槽是否存在——无则标缺口，不编造答案。
6. 失败→回步骤 1：检索噪声过大因别名未入索引——先补别名列再重扫。

**做到**：冲突表每行有路径:行号与分类；破例与时间线问题已标；unverifiable 未强裁。

### 3. 裁断、单一 SoT、登记建议

**做**
1. 真冲突给选项：保留 A / 保留 B / 合流改写 / 升未决；附影响面（对白键、任务 id、活动 id 列表，用 `rg` 生成）。
2. 用户选定后：改从属源、过时源加 `Status: Deprecated` + 替代指针，只留单一 SoT。
3. 新设定只列登记建议卡：标题、canon 级、影响面、建议权威路径——扩写交叙事导演，本步不编大段新史。
4. 活动例外写「范围、起止、不回写」声明；检查活动文案是否误用主时间线语气（`rg` 绝对年代词）。
5. 输出：裁断表、过时源列表、登记建议、未决项；文案修正指针 `dialogue-pass` / `copy-pass`；晋升指针 `promote-canon`。
6. 失败→回步骤 2：影响面列不出键/id——扩大检索范围补全后再裁。

**做到**：真冲突均有裁断或未决；过时源有废弃标记；无双 SoT；活动例外边界声明已落盘。

### 4. 回归抽检与索引日期

**做**
1. 对已裁断旧说法做关键词回归：`rg` 旧短语是否残留；残留则改或挂账（阻塞/可延后+误导风险说明）。
2. 抽检高曝光文本（主线开场、商店传说、加载提示键）各跑一轮检索。
3. 更新实体索引「last_verified」日期列与本轮扫描范围/未扫范围。
4. 在 PR/任务单贴冲突表摘要与回归命令，便于复查。
5. 失败→回步骤 3：回归仍大面积命中旧说——裁断未落地，回改从属源再回归。

**做到**：旧说残留=0 或显式挂账；索引日期已更新；扫描范围诚实可查。

下一步常接：`dialogue-pass` / `copy-pass`；入库 `promote-canon`。

## 细则

### A. 扫描范围
1. 对照 lore 圣经/Canon：人物关系、时间线、地理、能力边界、势力动机。
2. `rg` 专有名词跨 GDD/任务/对白/UI；一名多义列出。
3. 新设定必须有来源路径与批准状态；Discuss 结论不得当 Canon。
4. 时间线事件排序表；逆序或重叠无说明则开冲突卡。
5. 失败→升级叙事/CD：互斥设定需裁决。

### B. 冲突卡
1. 字段：`conflict_id|left|right|impact|options|decision|owner`。
2. 选项至少 2：改 A / 改 B / 限范围共存。
3. 影响面勾选：任务/对白/关卡门闸/美术设定。
4. 裁决后回写圣经与引用方；留 provenance。
5. 未裁决冲突不得标「设定已一致」。

### C. 闭合
1. 抽样 5 条新内容走读无冲突。
2. 信号：同角色两套动机无版本说明。
3. 工具：圣经文档、Canon、rg、冲突表。
4. 与 `promote-canon` 衔接晋升。
5. 检查体量达标则维持本细则作回归清单。
