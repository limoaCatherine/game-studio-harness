# 技能数值怎么填与校

## 何时用

- 技能包骨架已定要填数
- 伤害/控制强度漂或与关卡预算不对齐
- 需按技能等级/品质档位填表并同通道横向对照
- 改系数前需要异常扫描与验算

## 怎么做

### 1. 锁定技能包与公式对齐

**做**
1. 选定本批技能 id 列表与版本；冻结引用的公式 id 与顺序表版本 `order_version`。
2. **系数字段对齐公式项**：基础、倍率、加算区、乘算区、持续时间、段数等；可调字段至少显式挂 `base` / `coeff`（倍率）/ `add_zone`（加算区）/ `mul_zone`（乘算区），以及 `duration` / `segment_count` 等项目启用项。
3. 缺公式项或属性主键先回 `damage-formula-pass` / `attribute-framework`。
4. 标明每技能输出通道（与公式通道一致）。
5. 多段技能预先写 `seg_ratio[]` 空槽，避免后期只填总分。
6. 输出「技能×字段」可调矩阵；主键与技能包 `skill_id` 对齐。
7. 对照：技能包清单与公式目录交叉引用无断链。
8. 失败→回本步（或缺公式则回公式侧）：字段挂不上公式项。

**做到**：本批技能系数字段与冻结公式项对齐；可调/禁调分开；交叉引用无断链。

### 2. 填系数与档位对照

**做**
1. **按档位（技能等级/品质）填表**；同通道技能横向对照手感带宽（同阶输出/控制时长不得无解释偏离）。
2. **系数单位与公式约定一致**：百分数 vs 小数写死（全表同一约定，禁止混写）；落表前自检单位列。
3. 多段技能写清每段系数与快照点（与公式 `snapshot_at` 一致）。
4. 向制作方确认目标 TTK/斩杀线，不编造「标准系数」。
5. 验算槽：抽样技能代入公式得中间项与最终输出；边界必跑（0 防、满暴击、满易伤、打断中段等，用表内真实值）。
6. 失败→回本步：档位倒挂或单位混写未解释。

**做到**：档位表填齐；同通道横向对照有记录；单位约定成锚；验算抽样可指。

### 3. 异常扫描

**做**
1. 扫描至少覆盖：零伤、过量、**档位倒挂**、**与同阶技能严重偏离**、**冷却与代价不匹配**；可附加废技能/尖刺等。
2. 异常列表含技能 id、档位、指标、建议方向；分类标签建议：`zero_dmg|overkill|tier_invert|peer_outlier|cd_cost_mismatch`（可扩展，但不得只扫连招手感类）。
3. Buff 叠乘是否超出公式乘区显式登记。
4. PVE/PVP 若分表，分列扫描，禁止混用系数。
5. 不合格：倒挂未解释 → 回步骤 2 改系数或回公式侧改顺序。

**做到**：异常扫描清单闭环；档位/同阶/冷却代价类覆盖。

### 4. 落表与回归

**做**
1. 沙盒写入走 `excel-com-write`；晋升走 `tunable-table-diff`。
2. 回归验算槽：本批技能边界输入全过。
3. 影响面：依赖该技能的怪物/关卡推荐战力是否需同步。
4. 回滚说明与变更单附件。
5. 检查：正式簿回读与验算记录一致。
6. 失败→回步骤 2/3：验算不过或异常未闭环。

**做到**：验算槽回归通过且表变更可回滚。

## 完成检查

- [ ] 本批技能系数与冻结公式项对齐（含基础/倍率/加算区/乘算区）
- [ ] 档位对照与异常扫描清单闭环
- [ ] 验算槽回归通过且表变更可回滚

## 工具锚

- 验算槽（技能代入公式）
- 表引擎 COM/写入
- 版本库 diff

## 不在本文件

- 不改公式插入顺序（归 `damage-formula-pass`）
- 不重定义属性主键
- 不写技能叙事/特效演出全文

## 失败回哪一步

- 通道/字段挂不上公式项 → 回步骤 1（或回公式/属性框架）
- 档位倒挂/单位混写/同阶偏离 → 回步骤 2
- 异常未解释或未给方向 → 回步骤 2/3
- 落表回读或验算不过 → 回步骤 4（必要时回 2）

下一步常接：`excel-com-write` → `tunable-table-diff`。
