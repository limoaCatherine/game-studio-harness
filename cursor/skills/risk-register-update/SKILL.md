# 风险台账怎么更新

## 何时用

- 里程碑前复盘风险，或新依赖/裁剪引入风险
- 既有风险状态变化；活服大活动、认证、经济改版前要抬视图
- 「感觉不妙」需落成可观测信号

## 怎么做

### 1. 收集、命名、分流问题

1. 打开风险台账（`production/risks/` 或 sheet：`risk_id|title|category|status|owner|score|signal|next_review`）；表写入走 `excel-com-write`。
2. 从来源收条：依赖板、容量表、技术尖兵、经济 KPI 看板、合规日历、内容缺口、UX 死胡同、活服空窗；每条写短名+触发条件+影响面。
3. 用缺陷 tracker 过滤：已发生的标 **Problem** 并转缺陷/事故单号，移出台账「未爆」区；仅保留未发生风险。
4. 合并重复：`rg -n "RISK-|risk_id" production/`；拆「大杂烩」（把「技术不行」拆成可验证未知 + 尖兵结论日）。
5. 对照里程碑板关键路径与 `scope-cut-decision` 残留，补遗漏；本轮范围锁本里程碑/本赛季。

**做到**：台账每行有 risk_id；问题已链缺陷单；范围=本里程碑/赛季；与计划/裁剪互指。

### 2. 定级与早期信号（工具锚）

1. 相对序定级：阻断里程碑 / 可缓解 / 可接受；用 P×I 枚举写入 score 列，保持级差可读（不全员「高」）。
2. 每条写 **可观测早期信号**：指标名（看板/日志键）、检查点日期、或 tip 事件；工具面=Grafana/BI 看板、CI 红灯、日历提醒、试玩计数器。
3. 写 `next_review` 日期；用日历工具建复查事件；过期未查自动抬一级提示。
4. 经济/活服：信号对齐 KPI 口径槽；技术未知：信号含尖兵结论日，到期无结论=触发。
5. 合规/认证：信号=送审窗口日+材料齐备 checklist 路径；错过窗口升阻断。
6. 「感觉不妙」改写为具体看板/日期/日志键；改不了则标不可管理并请用户裁掉。

**做到**：分级完成；每条高/中风险有信号字段非空；复查日在日历可点。

### 3. 缓解、Owner、接受与关闭

1. 高/中风险：缓解动作写到可执行粒度（改哪张表 sheet.col / 关哪个 feature flag / 砍哪条范围）；Owner 人名/角色；升级条件。
2. 无法缓解标 Accept + 残余影响；无主高风险当场指定 Owner 或升阻断议题。
3. 优先降级方案（关功能、降强度、延后、只读）；若缓解=砍范围，必须有 `scope-cut-decision` 链接。
4. 关闭：写关闭理由、证据路径（提交/试玩记录/开关截图）、日期；关闭后若复发写回归条件。
5. 台账按 score 降序导出；阻断项置顶并链里程碑主人站会议程卡。

**做到**：高风险有 Owner+信号+缓解或 Accept 理由；与裁剪互链；阻断项在站会议程可点。

### 4. 演练、沟通、diff 归档

1. 阻断项进站会固定议题直到降级/关闭；会议纪要勾「信号是否触发」。
2. 活服开关类：写演练步骤（禁用→回滚→补偿→延长）与负责人；在预发环境实际点一次开关（或 dry-run 记录）。
3. 可能影响已预告内容：预备 `release-notes-stub` 口径草稿路径。
4. 用 `git diff` / 表 diff 归档本轮：新增/升级/降级/关闭列表+日期；接受类风险季度回顾日写入日历。

**做到**：演练槽有记录；对外口径草稿存在（若需）；台账 diff 可查。

## 做到

- 问题与风险已区分并分流
- 高风险有 Owner、可观测信号、缓解或 Accept
- 复查日在日历；阻断项有站会议程
- 与里程碑/裁剪互指；本轮 diff 已归档；活服类有演练记录（若适用）

## 失败回哪一步

- 问题与风险未分流、范围无边界 → 回步骤 1
- 信号只能写「感觉不妙」、复查日空 → 回步骤 2
- 高风险无主、缓解无可指字段/开关 → 回步骤 3（先补锚点）
- 演练点不动开关或无回滚步骤 → 回步骤 3 补齐后再标 Mitigating（步骤 4）

下一步常接：`milestone-plan`；技术未知 `rule-feasibility-check`；砍法 `scope-cut-decision`。
