# 构建阻断项怎么盘

## 何时用

- CI 红或产物缺失，要分清「哪条 job / 哪类签名」在挡
- 提测前要对齐本构建已知问题预算
- 崩溃/断言签名复发，需对照历史堆栈指纹
- 阶段切换争议要落到可修阻断清单

## 怎么做

### 1. 锁定构建身份与期望产物

1. 记下分支、SHA、流水线 run id、目标平台；缺 SHA 先向 CI 或用户索取，用具体 SHA 代替「最新」。
2. 打开仓库 CI 配置列出本轨相关 job 正式名（如客户端构建、单测、冒烟、打包）；抄出正式名。
3. 对每个必产物写期望路径槽：客户端包、测试结果、日志、符号包；路径以项目约定为准，缺则问。
4. 本盘只产阻断与预算占用；输出身份卡四行：SHA、run id、job 名列表、产物路径槽；存 `builds/<sha>/blockers_header.md`。
5. 身份不一致（测的包 ≠ run 产物哈希）先停，对齐后再往下。

**做到**：SHA+run id+job 名+产物路径槽可对人口述一致；无「最新构建」空指。

**不合格**：SHA 空或产物路径槽未问清 → 回本步索取后再盘。

### 2. 逐 job 读状态与产物

1. 打开 CI 控制台该 run：每条相关 job 记 `success/failure/skipped/cancelled` + 失败步骤名。
2. 失败 job：截取首个非片状失败块（断言名、exit code、异常首行）；路径写入 `builds/<sha>/job_<name>.log` 指针。
3. 成功 job：核产物真实落下且大小>0、时间戳对应该 run；空目录或占位说明当缺失。
4. 跳过 job：写清跳过原因；本轨本应跑却跳过，记为阻断候选。
5. 片状（同 job 同 SHA 偶发红）：标 `FLAKE` + 近 3 次重跑结果，不计入「已修」，也不装绿。
6. 任一必产物缺失：回到步骤 1 核对路径槽或重跑该 job；用本 SHA 产物，不用旧 run 顶替。

**做到**：每条相关 job 有状态+日志/产物指针；缺失与片状分列。

**不合格**：用旧 run 产物顶替本 SHA → 回步骤 1 对齐后重核。

### 3. 崩溃签名与断言指纹

1. 从失败日志/崩溃上报导出符号化栈；无符号则先取本 SHA 符号包再比。
2. 做签名指纹：顶帧函数名 + 异常类型（或 native 桶）；写入 `builds/<sha>/crash_signatures.md` 一行一条。
3. 对照历史库：`NEW` / `REGRESSED` / `KNOWN`；KNOWN 必须挂既有 bug id。
4. 断言失败：记测试全名与期望/实际摘要；同名断言跨 job 合并一条阻断。
5. 启动即崩：另记冷启复现步骤 ≤5 步与设备档；无复现则标 `CANNOT VERIFY` 所需项。
6. 签名对不上历史且无新单：开/更新缺陷单后再继续盘预算。

**做到**：每条崩溃/断言有指纹与 NEW/REGRESSED/KNOWN 标签；KNOWN 挂 bug id。

**不合格**：新签名静默吞或无符号化定根因 → 回本步补符号与开单。

### 4. 已知问题预算与阻断清单

1. 拉取本里程碑 known-issue 预算表（条数上限、严重度桶、Owner）；缺表向用户索取。
2. 把本构建 KNOWN 项填进预算格：已占用 / 剩余；超预算的 KNOWN 升级为阻断，写「超预算原因」。
3. 汇总三栏：`BLOCKER`（必产物缺失、新崩溃、核心 job 红、超预算）/ `WARN`（片状、跳过需补跑）/ `INFO`（预算内 KNOWN）。
4. 每条 BLOCKER 写返工：回哪一步（重跑 job / 修签名对应代码 / 补产物路径 / 砍范围降预算）+ 负责槽。
5. 输出 `builds/<sha>/blockers.md`：身份卡、job 表、签名表、预算占用、阻断清单；齐套后的提测结论交给 `build-acceptance`。

**做到**：阻断清单可执行；预算占用数字可见；文件含返工步骤。

**不合格**：清单无返工路径或预算数字不可见 → 回本步补齐。

## 做到

- SHA/run id/job 名/产物路径槽齐全且可对人口述
- 相关 job 均有状态与日志或产物指针；崩溃/断言已分 NEW/REGRESSED/KNOWN
- blockers.md 含预算占用与可执行返工步骤

## 失败回哪一步

- SHA 空、用「最新」代替、产物路径槽未问清 → 回步骤 1
- job 无日志指针、旧产物顶替本 SHA、片状装绿 → 回步骤 2
- 无符号化栈定根因、新签名静默吞 → 回步骤 3
- 预算表空却编造条数、BLOCKER 无返工槽 → 回步骤 4

下一步常接：修阻断 → `ci-smoke` / `client-bugfix`；齐套后再 `build-acceptance`。
