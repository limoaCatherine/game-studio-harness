# 通用交付表怎么填

## 何时用

- 本轮需要决策/开放问题/进度/交接摘要壳，而非领域专用表
- 表要与正文产物共登记，供下一手打开

## 怎么做

### 1. 选表

**做**
1. 按当前事件只打开用到的通用表：决策 / 开放问题 / 进度 / 交接摘要。
2. 领域专用表不在此填，指针回事件技能。
3. 确认表模板字段与本里程碑命名一致；无模板则先建最小四列表头再填。
4. 信号：表路径与工作项可互指。

**做到**：只用到的表已打开；领域表有回指。

### 2. 填事实字段

**做**
1. **决策表**：选项、选定、理由、批准人、日期。
2. **开放问题**：谁、何时、阻塞哪条证据。
3. **进度**：完成/进行/阻塞与证据路径。
4. **交接摘要**：下一手需要的三句话事实。
5. 禁止形容词堆砌；空字段标 N/A 并写理由。

**做到**：本轮用到的表关键字段齐全；无空话行。

### 3. 与产物共登记

**做**
1. 表路径与正文产物一并走产物登记。
2. **写后抽查一行可被下一手打开理解**——抽查失败则改写该行。
3. 过期开放问题要么关闭要么升级。
4. 多份拷贝时声明单一事实源路径；常接 `sync-state` / `status-digest`。
5. 工具/信号：表引擎或文档、产物索引、会话卡。

**做到**：表路径已进产物索引；抽查行可理解；过期问题已处理。

## 完成检查

- 本轮用到的通用表字段齐全可打开
- 表路径已进产物索引

## 不在此文件

- 领域专用数值/关卡表细则
- 事件全文
- 具体软件商品名

下一步常接：`artifacts-append`；`handoff-pack`；`sync-state`；`status-digest`。

## 不合格与返工

缺对照路径、表回读失败或日志对不上 → 返工对应步骤，不空口完成。

## 工具锚

- 里程碑与范围裁切记录 `.md`
- 会话 `loadplan.json` / `activated.json` 与 `~/.cursor/skills` / `agents` / `mcp.json` 点名对照
- 发版说明与 `sync-state` 状态摘要路径
