# 成长曲线怎么定与扫

## 何时用

- 升级/段位/好感等进度需定形并落表
- 前期过难、后期真空或收益倒挂
- 战力锚与内容解锁脱节
- 多条成长轴同窗口抢节奏

## 怎么做

### 1. 定主从轴与里程碑锚

**做**
1. 列成长轴：等级/突破/技能/装备等；声明主轴与从轴及同窗口关系（简图即可）。
2. 写关键里程碑空槽：`milestone_id | 解锁内容引用 | 战力跳变主键 | 系统开放`；目标感句写成可观察解锁/跳变/系统开。
3. 对齐内容解锁表与经济锚（`price-curve-pass` / 投放表）；冲突并列请用户裁。
4. 从轴不得抢主轴里程碑话术；同窗口总负担上限写成空槽不等式。
5. 输出 `progression/axes_milestones.md`；缺数字向用户索取，标假设不得当事实。
6. 里程碑无解锁引用：停在本步补引用再落曲线。

**做到**：主从轴与里程碑可点名；冲突已列；负担上限不等式可见。

### 2. 选曲线形状并字段化

**做**
1. 选项：线性、前缓后陡、阶梯突破、软上限+溢出、对数软帽、S 曲；每套写对前期挫败与后期真空的影响一句。
2. 定义相邻档约束字段：`cost_ratio_max` / `gain_ratio_min`（空槽不等式）；形状参数（斜率、软帽点、阶梯间隔）全部字段化。
3. 给 2 套形状+利弊（不编具体表数），用户选定主形状且参数字段化后再落表。
4. 多轴：从轴超负担上限则先砍从轴密度/代价，不削主轴里程碑。
5. 形状参数写入工作卡：`shape_id | params | 选定人 | 日期`。
6. 未选定形状不得进步骤 3；选定后改形状须回到本步重评负担上限。

**做到**：形状已选定且参数字段化；多轴负担有上限。

### 3. 落表列与累计/差分验算槽

**做**
1. 产品表列最低集：`tier | cost_delta | cost_cum | gain_delta | gain_cum | unlock_ref | attr_jump_key`；属性跳变主键必须存在于 `attribute-framework`。
2. 另建验算槽（沙盒 sheet）：输入 `tier` → 输出累计与差分两列对照锚；只看累计会漏单档尖刺。
3. 画/生成累计曲线与差分柱（Excel 图或导出 CSV 再绘）；目视尖刺与长平台。
4. 填写仅经 `excel-com-write` 沙盒。
5. 面板展示与 `attr_jump_key` 对齐说明：战斗内跳了面板不跳则记缺陷，回属性框架。
6. 验算槽路径写入任务；缺差分列则回到本步补列，不进入扫描。

**做到**：字段齐全；累计+差分验算可跑；沙盒路径明确。

### 4. 扫描异常档并返工

**做**
1. 扫四类：单档 `cost_delta` 尖刺、`gain_delta` 倒挂、长真空（连续多档无 `unlock_ref` 且无战力跳变）、与内容解锁错位。
2. 修法优先级：插解锁引用 > 改 `cost_delta` / `gain_delta` > 调形状参数；选定后更新沙盒再重跑验算。
3. 异常下降或写接受理由（须用户确认）；高风险档绑定试玩抽检——至少跨过一个里程碑档。
4. 晋升走 `tunable-table-diff`；晋升前差分图与累计图各存一版证据路径。
5. 不合格：尖刺未消 → 回步骤 3 改字段；形状不合适 → 回步骤 2；锚冲突 → 回步骤 1。
6. 阻塞项 vs 可延后项分列；可延后写为何不挡本里程碑。

**做到**：异常档已扫描并有修法；验算重跑通过或理由已批；返工步骤号明确。

下一步常接：`price-curve-pass`；属性跳变 `attribute-framework`；晋升 `tunable-table-diff`。
