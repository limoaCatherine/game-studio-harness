# 从 GDD 怎么写用例

## 何时用

- AC/公式要落成可执行用例
- 要 GDD↔用例追溯，防孤儿
- 自动化前要用例库
- 边界与副作用易漏

## 怎么做

### 1. 抽取可测点

1. 读 GDD 公式、状态转换、边界、副作用与故事 AC；每点写：输入、动作、期望观察；初标自动或手工。
2. 公式类拆：正常值、0、最大、非法、空目标；负数/溢出单独成案，不并进「非法」。
3. 状态机类拆：合法转移、非法转移、重入、超时。
4. 副作用写「应发生」与「不应发生」成对点（例：发奖应到账 / 不应重复到账）。
5. 从 Edge Cases 节逐条拉点；漏则记 GDD 缺口；每点可指 GDD 段落锚（节名/行号/条款 id）。

**做到**：可测点覆盖公式/分支/副作用；每点可指 GDD 段落锚；观察用可测描述。

### 2. 写 GWT

1. Given 环境/数据（含夹具名）；When 动作；Then 可观察结果+断言/日志点。
2. Then 写具体数值、状态名、UI 可见文案或日志「字段=值」；非法输入写清期望错误码或玩家可见提示键。
3. 每 AC 至少一条对应用例；边界集按约定补齐；用例 ID 稳定（`TC-<system>-<nnn>`），后续追溯不飘。
4. 集成类断言跨系统状态（背包+邮件+货币），不只 UI 文案。
5. 用例写入用例库表/目录；xlsx 走 `excel-com-write`。

**做到**：GWT 可执行；边界与副作用不空；Then 可观测。

### 3. 建追溯矩阵

1. 矩阵列：`AC_ID | TC_ID | 自动? | 缺口级别`；无用例的 AC 标缺口；无 AC 的用例标可疑。
2. 缺口按风险排序：公式/金钱/存档优先补（P0）；可疑用例周清：补 AC 或删除。
3. GDD 变更时同步改矩阵；矩阵供 `regression-pack` 消费。
4. 矩阵路径写入 QA 计划引用，避免孤儿文件。

**做到**：无孤儿 AC（每 AC≥1 用例）；可疑用例可见并处置。

### 4. 标自动化候选

1. Logic/边界优先自动；纯观感留手工；强时机/真网络步骤标「待可注入时钟/假网络」。
2. 每用例写自动/手工标记与理由；建议目录路径回填；已有自动的写测试文件路径。
3. 自动化候选汇总一列「阻塞标签」：无阻塞 / 待可注入时钟 / 待假网络 / 待真机；有阻塞的不计入本迭代自动完成数。
4. 交给 `case-automation-map` 排 ROI。

**做到**：每用例有自动/手工标记与理由；自动候选有路径/tag；阻塞标签显式。

## 做到

- AC 均有对应用例或缺口；GWT 可执行且 Then 非空
- 边界覆盖约定；追溯矩阵完整；自动化候选已标

## 失败回哪一步

- 可测点靠形容词、缺 GDD 锚 → 回步骤 1
- Then=「正确/报错」无码、ID 不稳 → 回步骤 2
- 孤儿 AC、可疑用例未处置、矩阵与 GDD 漂 → 回步骤 3
- 阻塞标签空却计入自动完成 → 回步骤 4

下一步常接：`case-automation-map` → `auto-test-scaffold`。
