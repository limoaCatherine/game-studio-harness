# 拼装执行单

## 何时用

加载计划里**执行类**事件（不含验证 / 登记 / 交接 / 同步）≥ 3，需要排出顺序或并行面。

两件及以下：按依赖口头排序，不点本技能。

## 怎么做

### 1. 读名单并分类

1. 读当前加载计划与会话能力名单。名单只含点名项。
2. 执行类与收口类分开。收口 = `verify-gate` / `artifacts-append` / `handoff-pack` / `sync-state`。
3. 点了职种：执行单只写该职种一步，下一步看 `craft_open`；不要把 `uses_skills` 全展开进 flow。
4. id 不在菜单 → 回定档或先刷新菜单。

**做到**：执行类 ≥ 3 且可检索。

### 2. 按依赖排阶段

1. 设计 → 表 → 实现 → 验证。
2. 两项无数据读写依赖才标并行。岗位职责不同的步骤标给对应职种子代理，不由主会话串演。
3. 收口挂链尾。
4. 改表步骤按实际点名的那一层展开，不把未点名的 Excel 层插进执行单。

**做到**：无环；收口在尾。

### 3. 写执行单

1. 运行 `python ~/.cursor/harness/scripts/建议执行单.py <会话> --force`（cwd = 业务根），或直接写 `.harness/sessions/<会话>/flow.json`。
2. 名单增删后回定档再生成名单，再重跑本脚本。

**做到**：会话内有 `flow.json`，步骤与名单一致。

## 完成检查

- 执行类 ≥ 3 才使用本技能
- `flow.json` 收口在链尾

## 不在此文件

- 各事件正文
- 产品表字段规范
