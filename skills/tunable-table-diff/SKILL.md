# 数值表 Diff 怎么做与晋升

## 何时用

- 沙盒数值要晋升正式
- 需审查谁改了哪些单元格
- 热更/版本合入前要精确变更集
- 跨职种改表冲突需合并

## 怎么做

### 1. 锁定对比范围

**做**
1. 声明工作簿、sheet 列表、主键列、允许变更列；禁改列单独列出。
2. 确认沙盒与正式表头一致；列增删先做人审；表头不一致则输出列 diff。
3. 选定 diff 粒度：单元格 / 整行 / 主键集合。
4. 记录对比双方文件版本/时间戳，保证可复现。
5. 输出范围卡：簿、sheet、主键、允许列、禁改列、粒度。
6. 范围卡与禁改列打印/贴任务页；写前再读一遍。
7. 表头不一致时输出列 diff（勿按列位置静默对齐）。
8. 不合格项写返工回到哪一步（步骤号）。
9. 涉及产品表时：沙盒编辑走 excel-com-write，晋升另开 tunable-table-diff。

**做到**：对比范围卡明确。

### 2. 生成结构化 diff

**做**
1. 输出：新增行、删除行、修改单元格（旧→新）、类型变化；必须含旧值→新值。
2. 按主键聚合；孤儿行（无主键/重复主键）单独列表。
3. 输出可按主键过滤的增删改清单，供人审阅（整表覆盖不算 diff）。
4. 按风险列排序（见下一步）供人审，而非只看行数统计。
5. 导出 diff 摘要文件路径写入任务备注。
6. 结构化 diff 必须可按主键过滤；只给整表 hash 不算 diff。
7. 孤儿行与重复主键单独成节，晋升前必须清或接受。
8. 缺项目数字/档位时向用户索取，标假设的条目不得当事实引用。
9. 列出本步阻塞项 vs 可延后项；可延后必须写为何不挡本里程碑。

**做到**：增删改可分类审阅。

### 3. 风险分级

**做**
1. 启发式：公式相关/经济投放/伤害系数/掉率=高；UI 排序=中；纯展示文案=低。
2. 高风险绑定必测用例槽或下游 Skill（damage-formula / inflation-stress / price-curve）。
3. 同一主键两边都改→并列冲突，同一主键两边都改则并列冲突请双方裁。
4. 禁改列出现变更→直接阻断晋升。
5. 输出分级表：主键、字段、旧→新、风险、必测槽。
6. 高风险必测槽写具体用例名或 Skill id；空槽不得标高风险已覆盖。
7. 冲突行导出并列视图给双方 Owner，冲突行导出并列视图给双方 Owner。
8. 涉及产品表时：沙盒编辑走 excel-com-write，晋升另开 tunable-table-diff。
9. 若与支柱/冻结范围冲突，停手升级决策，不私下削承诺。

**做到**：高风险已分级并绑定必测；冲突未自动合并。

### 4. 晋升或回滚

**做**
1. 晋升：确认范围→`xlsx_merge_changeset` 只回写本轮记录格（走 `excel-com-write` 配方，副本只在 `沙箱/`）→回读抽样→记变更摘要。禁止整本覆盖正式表。
2. 回滚：按主键集在沙箱改，再 `xlsx_merge_changeset` 只合记录格。不要写 rollback，不要用 rollback 拷回正式表。
3. 正式簿只经 changeset 合并写入；晋升必须回读抽样。
4. 晋升后通知下游：高风险经济/战斗变更回扫对应分析 Skill。
5. 抽样失败则停止并回滚已写子集。
6. 回读抽样至少覆盖高风险行的 20% 或不少于 3 行（向用户确认抽样策略）。
7. 回滚演练：对测试主键走一次撤销，确认快照可用。
8. 列出本步阻塞项 vs 可延后项；可延后必须写为何不挡本里程碑。
9. 不合格项写返工回到哪一步（步骤号）。

**做到**：晋升/回滚可审计；抽样回读通过。

下一步常接：高风险经济/战斗变更回扫对应分析 Skill。
