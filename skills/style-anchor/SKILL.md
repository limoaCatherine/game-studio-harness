# 风格锚点怎么写

## 何时用

- 开原画/高模/UI/外包前要可裁决标准
- 职种风格互相打架，或有参考板但无禁区/拒收句
- 换画质档仍要保记忆点

## 怎么做

### 1. 收约束并建参考板

1. 打开支柱卡与平台画质档；用 `rg -n "pillar|记忆点|禁区" design/` 抽出必须保留的视觉记忆点与绝对不要的样子。
2. 在 PureRef / Figma moodboard / 本地 `art/refboard/` 建参考板：每张图旁注释「学什么 / 不学什么」各 ≥1 条；工具面=图注图层或侧栏文本。
3. 若已有 art-bible：逐块标 Complete / Empty / Placeholder；Complete 只读；Empty 本轮必填。
4. 收集旧外包 Brief / 拒稿邮件：提炼已生效隐性禁区，写入禁区草稿表。
5. 平台目标与画质档写入约束栏；理想 4K 与移动档冲突并列「理想 | 约束 | 本版选用」。

**做到**：参考板 ≥8 张且每张有学/不学注；Complete 块清单可见；本版选用档写死。

### 2. 一句规则 + 检验句锁定

1. 起草一句视觉规则 + 2～3 条原则；每条附「当 X 模糊时选 Y」检验句，并挂回支柱 ID。
2. 给 2 套侧重点（识别度优先 / 工期·性能优先）；用户锁定后写入锚点文首 + 版本号 `vMAJOR.MINOR`。
3. 拿 1 个灰色案例（真实争议或合成）用检验句裁决并记录；不通则改句。
4. 规则句写清优先级：冲突时保谁砍谁；避免「既要 A 又要反 A」无取舍。
5. 把锁定句同步到外包 Brief 模板页眉（Figma cover / doc header）。

**做到**：文首有锁定句+版本号；灰色案例裁决记录可查；Brief 页眉已引用版本。

### 3. 形状 / 色彩 / 材质 / 光氛（工具硬锚）

1. **形状**：写棱角-圆润轴与比例；在参考板用轮廓描线标远距必须可辨的剪影控制点（头饰/武器外轮廓）。
2. **色彩**：在 Photoshop / Figma 取色器采主色 ≥5 个，写入 Hex + 语义角色（威胁/友好/中立/UI 强调）；另给色盲备份通道（形状/图标，不只靠色相）。
3. **材质与光氛**：写允许噪声级别、边缘硬度、对比；与画质档冲突写「理想 vs 约束」。
4. 在看图器（引擎 Viewport / PureRef / Figma）做 **side-by-side**：候选稿 | 锚点正例 | 锚点反例，三栏同缩放；记录比对结论。
5. 四块各写「可接受 / 拒收」边界各 ≥1；打开参考墙核对四块互不打架，打架先裁。

**做到**：主色 Hex 表齐全；并排比对至少完成 1 轮有结论；四块对错边界可执行。

### 4. 拒收标准、禁区与职种切片

1. 写 **拒收标准（Reject criteria）≥6 条**：格式 `现象 | 检测面（缩图/取色偏差/并排比对）| 动作（拒收/例外批准人）`。
2. 禁区 ≥6：每条带例外批准人角色；用 2 张参考试跑拒收——应拒未拒则改标准。
3. 角色/场景/UI/VFX 切片：各职种「优先保 / 可降级」；摘录入各职种开工包，不只传总文档。
4. 画质档切换时：在引擎低档预览或压缩预览再跑记忆点勾选；不保则回步骤 3 改四块或降级策略。
5. Complete 块变更走显式升版本；正式句只在升版文档里改。

**做到**：拒收标准 ≥6 且试跑通过；四职种切片可发包；版本号被 Brief 引用。

## 做到

- 参考板有学/不学注；一句规则+检验句+版本号齐全
- 主色 Hex 表与语义角色齐全；色盲备份通道写明；并排比对有记录
- 拒收标准 ≥6，禁区含批准人；试跑通过；旧 Complete 块未被静默重写

## 失败回哪一步

- 参考板无「不学什么」、支柱记忆点抄不进板 → 回步骤 1
- 检验句裁不出灰色案例、规则无优先级 → 回步骤 1 补板或收窄规则句
- Hex 表空、并排比对无法判拒 → 回步骤 2 补句后再填四块（步骤 3）
- 拒收试跑失败、聊天偷改正式句 → 回步骤 3 收紧阈值，步骤 4 升版发布

下一步常接：`concept-key-art`；资产开做前对齐本锚点。
## 锚点条目可引用格式

### A. 必填字段

1. 爱憎参考各≥3（可链图床/版本库），每条一句「学什么/不学什么」。
2. 色：主色/辅色/禁色；光：主光方向与软硬；剪影：远距可辨特征 3 条。
3. 平台画质档约束：理想画风 vs 本版可制作成本冲突时写「本版锚」。
4. 禁区：不可出现的纹样/暴露度/文化雷区——评审对照表。
5. 版本号与生效范围（角色/场景/UI/VFX 哪些域强制）。

### B. 使用方式

1. 概念开稿前强制读本版锚；评审逐条批注「符合/偏离+改法」。
2. 偏离须用户批准并记变更，禁止静默漂。
3. UI/VFX 引用同一锚的色彩与对比度条款，避免子系统自搞一套。
4. 锚点变更升版本并通知所有在制 Brief。

**检查信号**：任意在制资产能指出锚点版本号；评审记录有锚点对照勾选。
## 检查清单（密化）
1. 爱憎参考与禁区表可打开；版本号非空。
2. 远距三特征可复述；色光剪影条目完整。
3. 本版锚与理想锚冲突已显式决策。
4. 在制 Brief 均引用同一版本；抽查 2 份。
5. 变更升版并通知角色/场景/UI/VFX。
