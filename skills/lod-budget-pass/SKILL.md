# LOD 预算与距离怎么定

## 何时用

- 竖切前要定角色/场景 LOD 政策
- 同屏掉帧归网格过密
- 外包 LOD 级数或比值不合
- 多平台要分档距离表

## 怎么做

### 1. 建预算基线

1. 向用户索取目标设备档、同屏角色/物件上限、Asset Standards 面数档；无数字不开私有「经验档」。
2. 起草每类型（主角/怪/场景模块）LOD 级数、相对 LOD0 面数比、切换距离初值；距离标「待实机」。
3. 写网格耗时占帧预算切片；与特效/UI 切片分开，超网格先踢 LOD 再怪特效。
4. 遮挡剔除、Impostor、HLOD 与角色 LOD 分账，同一批三角面只记一次。
5. 分平台表：低端/中端/高端各一行距离与比值；各档独立填，不全平台共用一套距离。
6. 把初值表版本化，通知角色/场景/外包同一版本；面数统一用三角面记账。

**做到**：分平台预算表有初值；切片比例可复述；记账口径统一为三角面。

### 2. 扫覆盖与比值

1. 扫资产库：缺 LOD 级的列出；最小可玩/主角缺级=阻塞。
2. 读每级三角面数，算相对 LOD0 比例；落在表±容差外则减面或调策略（哪级合并）。
3. 减面时锁头/肩/武器/建筑外轮廓控制边；自动减面后必须人工看剪影。
4. 各级尽量共享材质与贴图，避免切换时爆 IO；若某级起合并槽，写明起始级。
5. 命名与主模同一 Domain/Type/Name，仅 LOD 后缀不同；后缀风格与 `export-naming-gate` 一致。
6. 记录每资产各级实际面数进覆盖表；打开面数统计面板核对。

**做到**：覆盖表齐；比值超差有处置；材质共享策略写明。

### 3. 保剪影

1. 远景级做缩图对比：头/肩/武器或建筑天际线仍可辨类型（敌我、职业、楼型）。
2. 塌成不可识别块：回减面设置或加保护边，远景级同样过人工剪影审。
3. 引擎里拉距离看切换：狂闪则加迟滞（hysteresis）或重叠带；参数与程序/TA 对齐。
4. 阴影投射可用更激进 LOD，但写例外，避免误用于主相机。
5. 透明/镂空资产切换破洞：检查 alpha 与减面顺序，必要时该级禁用透明减面。
6. 用线框+实体双视图对比各级轮廓，记录不可接受级号。

**做到**：中远景仍可辨类型；切换无狂闪。

### 4. 实机标定

1. 在目标机或同等档录制：切换距离、同屏峰值帧时、过热时降级是否触发。
2. 超员时写踢 LOD/限流策略（谁先降、降到哪级）；策略可执行而非口号。
3. 过场强制 LOD0、反射/镜像用低 LOD 等例外写入表。
4. 与 HLOD/Impostor 划界：同一建筑勿既算模块 LOD 又算 HLOD 全额。
5. 用实机结果改距离表并升版本；编辑器估距离只作初值，标定以实机为准。
6. 回归：改表后抽 2～3 个代表场景再录峰值。

**做到**：距离表经实机改过；同屏策略可执行。

### 5. 政策落地与外包对齐

1. 把分平台距离表与面数比写进 Asset Standards 或等价文档并升版本。
2. 外包收包清单增加：LOD 级数、面数比、剪影截图；缺则拒收并退回补齐。
3. 编辑器默认距离初值改为实机标定后的表，避免美术按错距离预览。
4. 抽 1 个主角+1 个场景模块做完整 LOD 切换录屏归档。
5. 与 `perf-budget-check` 对齐网格切片口径，避免双计。
6. 下里程碑开始前重扫覆盖表，防新资产漏级。

**做到**：政策文档已升版；外包可执行；抽检录屏在。

## 做到

- 分平台 LOD 级数/面数比/距离表齐全且经实机标定
- 缺级与超比已处理或排期显式；远景剪影可辨；切换有迟滞策略
- 同屏限流可执行；与 HLOD/Impostor 无双计

## 失败回哪一步

- 无档位数字/平台表空 → 回步骤 1
- 缺级、比值超差、材质每级独立炸 IO → 回步骤 2
- 远景不可辨、切级狂闪 → 回步骤 3（必要时回 2 减面）
- 仅编辑器估距离、同屏策略空话 → 回步骤 4 实机标定
- 外包仍按旧表、覆盖回弹 → 回步骤 5 升版通知并重扫

下一步常接：`perf-budget-check`。
## 加厚：LOD 比值与引擎识别约定

### A. 面数比与命名（公开管线常见起点，须项目化）

1. 记账一律三角面；DCC 显示四边面时先换算再填表。
2. 常见起点（仅作起草，实机后改）：LOD1≈50%、LOD2≈25%、LOD3≈10% 相对 LOD0；超差 ±项目容差则减面或合并级。
3. 同 FBX 多物体后缀 `_LOD0/_LOD1...` 或分文件同名核+后缀；导入器「导入网格 LOD」开关与预设绑定，禁止手工忘勾导致只进 LOD0。
4. 角色远景级可同步做骨精简（面部/手指/饰品骨移除）与影响数下调；与 `skin-weight-pass` 的影响骨上限分档一致。
5. 静态物件可走自动减面作初值，但剪影控制边（屋顶、雕像外轮廓）必须人工过目；Nanite/自动方案启用时仍要写「本资产是否豁免传统 LOD」例外。
6. 切换迟滞：记录屏幕尺寸百分比或距离+hysteresis；狂闪先加迟滞再改减面。

### B. 同屏与分账

1. 同屏角色/物件上限来自用户/制作人，不编造；超员时踢 LOD 顺序写清（远→近、装饰→主角）。
2. HLOD/Impostor 与模块 LOD 分账：同一建筑三角面只进一本账。
3. 阴影投射可用更激进 LOD，表中单独列「Shadow LOD」免误用于主相机。
4. 外包收包：级数、每级三角面、剪影缩图三件套缺一拒收。

**检查信号**：覆盖表无空级；实机录屏含切级；政策文档版本号与编辑器默认距离一致。
