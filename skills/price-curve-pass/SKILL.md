# 物价曲线怎么定与扫

## 何时用

- 商店/打造物价需曲线
- 性价比塌陷或永不值/唯一超值
- 战力锚与价格脱节
- 需与产销地图对齐的价锚

## 怎么做

### 1. 选择价格锚

**做**
1. 候选锚：期望获取时间（Teq）、基准货币持有曲线、战力/进度锚；每锚写测量窗口与数据来源字段。
2. 读产销地图与成长曲线；冲突时并列 2 套锚策略+利弊请用户选。
3. 声明适用目录（哪些商店/配方）与非适用（活动特价另表，不混算常驻锚）。
4. 检查关键 Sink 是否随水龙头增速缩放；不缩放则本曲线会阶段性失效，先标风险。
5. 向用户索取锚的目标带（空槽）；不编造「合理 Teq」。
6. 锚测量窗口与产销净流量窗口对齐；窗口不一致先统一再比价。
7. 非适用目录（活动特价）单独索引，扫描时常驻/活动分跑。
8. 与相邻 Skill 的主键/事件名对读一次；漂移立刻改名或开迁移。

**做到**：锚策略已选定；适用范围清晰。

### 2. 建立档位与价带

**做**
1. 定义档位轴（品阶/天数/战力段）；每档写价格字段名、锚对照式（空槽）、允许浮动带。
2. 写性价比规则：永不值=锚收益长期低于持有成本；唯一解=同档仅一项显著超值；严格占优=同成本更高收益。
3. 列需改 sheet/列；产品表走 `excel-com-write` 沙盒建价带列。
4. 同锚下收益/成本排序表头预备好，供下一步机器或手工扫描。
5. 硬通货与软通货分表或分列再比价。
6. 价带浮动带写成不等式字段；超带项自动进问题清单。
7. 软硬通货分列后做一次「误比」抽查，防止跨币种超值误判。
8. 本步交付一句话变更摘要（改了哪些价带字段）。

**做到**：档位与价格字段可填；规则可扫描。

### 3. 扫描问题项

**做**
1. 按规则扫目录/配方价：记对象、问题类型（永不值/唯一解/倒挂/占优）、规则 ID。
2. 对问题项给选项：调价 / 改奖励量 / 改门槛 / 移出常规目录；写对产销净流量副作用。
3. 战力锚变更时同步检查成长相关价带是否漂移。
4. 活动特价：只扫「是否污染常驻锚展示」；定价另表，不在本步当常驻解。
5. 输出问题清单供用户选定处置。
6. 问题项处置写对 sink-source 净流量副作用一句；无副作用声明也要写「无」。
7. 缺项目数字/档位时向用户索取，标假设的条目不得当事实引用。
8. 记录本步使用的文档/表版本号；无版本不进入下一步。

**做到**：永不值/唯一解清单可见。

### 4. 沙盒改价与一致性

**做**
1. 沙盒改选定价格字段；生成与正式表的行列级 diff 摘要。
2. 确认展示价与实扣字段同步；只改展示不改实扣视为失败。
3. 改完重跑扫描：问题项应下降或有明确接受理由。
4. 晋升走 `tunable-table-diff`；高风险价改绑定必测购买路径。
5. IAP/硬通货档交 `iap-catalog-check` 再核一层，本步不代替 SKU 合规。
6. diff 摘要与展示/实扣一致性检查同页交付；缺一页不晋升。
7. 改价后抽 1 条购买路径（沙盒）核对实扣字段。
8. 用一条最小可观察用例验证本步输出（不编造样例数值，向用户索取或标空槽）。

**做到**：沙盒 diff 可审；展示与实扣一致。

## 失败回哪一步

- 锚未选定或窗口与产销不对齐 → 回步骤 1
- 档位/价带字段不可扫 → 回步骤 2
- 永不值/唯一解无处置 → 回步骤 3
- 展示与实扣不同步或 diff 缺失 → 回步骤 4

下一步常接：晋升 `tunable-table-diff`；硬通货目录 `iap-catalog-check`。
