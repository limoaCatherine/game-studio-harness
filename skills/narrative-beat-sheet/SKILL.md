# 叙事节拍怎么排

## 何时用

- 章节/活动故事要从零搭结构或大改弧
- 玩法与叙事抢时间轴；需先排节拍再写对白
- 分支点未设计或假选过多；要给关卡/任务挂叙事锚

## 怎么做

### 1. 定弧、主题、版本与预算

1. 写弧陈述：起点→转变→终点；主题一句；非目标情节单列。
2. 检索支柱：本弧服务哪条；超出标砍/延后。
3. 列出场人物：欲望一句 + 玩法功能；无功能则合并或删。
4. 写玩法-叙事同向检查句；失调给「改玩法/改主题」选项。
5. 索取对话/过场时长预算；冻结弧版本标签（章节/活动 id）。
6. 不合格：预算空或挂不上支柱 → 先补/裁范围。

**做到**：弧卡含陈述/主题/非目标/预算/版本标签；挂得上支柱。

### 2. 填节拍表并挂钩子

1. 表列：beat_id、t_sec、place、player_action、reveal、emotion、forced_or_skippable、hook_id、budget_risk。
2. 每拍必须有玩家行动或标可跳；纯过场无行动→改可玩触发/可跳旁白/任务步进。
3. 每拍挂下游钩子 id（quest/encounter/level-goal）；检索确认存在或标空槽。
4. 估强制段累计秒；超预算标 risk 并写拆法。
5. 与 pacing-pass 轴对照：叙事高压不得与战斗尖刺无休息背靠背。
6. 不合格：强制累计超预算且无拆法 → 回改预算或砍拍。

**做到**：beat 表无空玩家行动（除非可跳）；钩子可检索；强制累计有拆法。

### 3. 分支覆盖与能动性

1. 真分支 vs 假选：无世界/任务后果的选项删或改合流。
2. 门闸清单：技能/道具/情报/任务旗；缺门闸写退化或延后拍。
3. 必出 beat 可达性检查；锁死路径标红。
4. must_ship 列勾选本版本必达拍。
5. 对白/任务挂点字段名稳定供下游引用。
6. 不合格：假选过多或必出不可达 → 回步骤 2 改钩子/合流。

**做到**：假选已删或改合流；门闸可达；must_ship 已勾。

### 4. 映射关卡/任务并冻结变更

1. 映射表：beat→level_goals / quest / dialogue 文件路径。
2. 变更 beat 勾选影响面三列（关卡/任务/对白）。
3. 冻结本版叙事包版本；主线改动需评估。
4. 输出 beat 表、门闸清单、预算风险、未挂钩子列表。
5. 入库文档仓；事件名给程序与关卡。
6. 不合格：下游需猜触发名 → 回补 hook_id。

**做到**：映射与影响面表入文档仓；hook_id 下游可引用。

## 做到

- 弧卡含陈述/主题/非目标/预算/版本标签
- beat 表无空玩家行动（除非可跳）且钩子可检索
- 强制累计秒≤预算或有拆法；门闸可达
- 映射与影响面表已入文档仓

## 失败回哪一步

- 步骤1（定弧、主题、版本与预算）：预算空或挂不上支柱 → 先补/裁范围。
- 步骤2（填节拍表并挂钩子）：强制累计超预算且无拆法 → 回改预算或砍拍。
- 步骤3（分支覆盖与能动性）：假选过多或必出不可达 → 回步骤 2 改钩子/合流。
- 步骤4（映射关卡/任务并冻结变更）：下游需猜触发名 → 回补 hook_id。

下一步常接：`quest-spec`；`dialogue-pass`；`pacing-pass`；`level-goals-spec`；`narrative-designer`；`lore-consistency-check`。

## 工具锚

- 节拍 / 对白稿 `.md` 与分支表 `.xlsx`
- 关卡或任务配置引用路径
- 评审记录写入 `.harness/artifacts/`

## 不在本文件

- 对白全文润色
- 任务状态机逐字段终稿可另开 quest-spec
- 数值奖励经济终裁
- 关卡灰盒几何
