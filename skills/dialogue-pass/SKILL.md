# 对白怎么写与审

## 何时用

- 任务/NPC/过场对白要落盘或大改
- 选项无后果、假选过多、声线崩坏、超框或本地化键不稳

## 怎么做

### 1. 定场景、声线与玩法约束

1. 打开角色声线卡：摘用词偏好、禁忌、情绪基线；本场偏移写入节点备注。
2. 在对白图/对白表建本场文件；场景目标一句 + 非目标单列。
3. 玩法约束写入节点元数据：战斗中可否跳、是否停世界、快进、重谈是否重置后果；字段名与 quest-spec 对齐并可检索。
4. 索取对白框字符档与分行规则；开字符计数列；无档不硬限。
5. 必读规则（消耗/门控）升到 UI 提示键槽，不靠可跳对白独扛。
6. 不合格：声线卡缺失或任务字段名找不到 → 回补卡/补 quest-spec 再开写。

**做到**：场景文件已建；声线要点与可跳策略写入节点元数据；字符档有来源；必读项有 UI 键槽。

### 2. 节点图先结构后填词

1. 画出开场钩→信息交换→选项→收束；每节点标说话人与玩家动作（听/选/走）。
2. 每个选项写后果槽：任务步进、关系值、世界旗、合流节点；无后果则删选项。
3. 条件行显式引用状态字段名，禁止散文条件。
4. 填词后跑字符计数：超框先砍信息密度再润色；墙字段拆节点。
5. 变量用命名占位符；键名稳定后只改文本列。
6. 不合格：选项后果未在任务表登记 → 回补字段名再连线。

**做到**：节点图可导出；选项皆有后果或已删；超框已处理；条件字段可检索到定义。

### 3. 分支覆盖与任务接线

1. 建分支覆盖矩阵：行=选项/条件边，列=后果字段/合流点/重谈规则/已走查。
2. 主路径走查 1 次 + 每选项分支至少 1 次；失败标回改节点 id。
3. 合流点写清共享态恢复；永久分叉须有下游内容预算，否则改合流。
4. 互斥选项用显式旗，与任务互斥表交叉检索。
5. 测强制段时长；超预算拆拍或改可跳。
6. 不合格：未接线后果或死胡同 → 回步骤 2 补边/删节点。

**做到**：覆盖矩阵无空后果行；强制段时长落预算或有拆法；合流/分叉策略有备注。

### 4. 声线、可玩性与本地化定稿

1. 对照声线卡试读：破格/OOC/全员一口吻标行号回改。
2. 关对白/跳过后跑玩法：不知目标则补任务指引 UI。
3. 检索人名地名事件键，对接 lore-consistency-check；冲突先裁断再定稿。
4. 标本地化风险键；输出定稿表：键、文本、条件、后果、可跳、本地化注。
5. 产品表存对白则走表沙盒写入；键冻结后只改文本列。
6. 不合格：大段 OOC 或设定冲突 → 回矩阵定位节点再改词。

**做到**：定稿表可交文案仓/版本库；跳过后仍能完成目标；禁词与 lore 冲突已处理或升级。

## 做到

- 节点图与覆盖矩阵无空后果行
- 强制段时长落在预算或有拆法记录
- 跳过后仍能靠 UI/任务指引完成目标
- 定稿表可交文案仓/版本库且禁词与 lore 冲突已处理或升级

## 失败回哪一步

- 步骤1（定场景、声线与玩法约束）：声线卡缺失或任务字段名找不到 → 回补卡/补 quest-spec 再开写。
- 步骤2（节点图先结构后填词）：选项后果未在任务表登记 → 回补字段名再连线。
- 步骤3（分支覆盖与任务接线）：未接线后果或死胡同 → 回步骤 2 补边/删节点。
- 步骤4（声线、可玩性与本地化定稿）：大段 OOC 或设定冲突 → 回矩阵定位节点再改词。
