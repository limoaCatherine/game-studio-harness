# 状态同步怎么做

## 何时用

- 工作项/会话卡/计划/产物索引互相打架
- 交接或周报前需要一句话真实进度

## 怎么做

### 1. 读四面状态

**做**
1. 读 `.harness/state.json` 与会话 `current.md`，再对照加载计划、产物索引、任务流水。
2. 列出声称完成但无验证报告等不一致。
3. 列出计划内未做技能与路径 404。
4. 范围已变则标记需回定档。
5. 信号：不一致清单。

**做到**：不一致清单非空或显式「四面一致」。

### 2. 当场对齐

**做**
1. 能对上的改会话卡字段。
2. 范围变了回 `route-task` 改计划并重激活。
3. 主源是 `.harness/state.json`。
4. 把一句话进度与下一步写回当前行。
5. 不合格：多源互相矛盾未标主源。

**做到**：主源已声明；一句话进度可引用。

### 3. 通知下一手

**做**
1. **把进度句挂到交接包或 `status-digest` 引用**（显式路径/锚点，不只口头说）。
2. **登记若有新快照**（产物索引或会话卡快照字段）。
3. 关闭已无意义的旧会话标签。
4. 确认下一手打开即见同一进度。
5. 工具/信号：会话卡、loadplan、产物索引。

**做到**：进度句已被交接或 status-digest 引用；新快照已登记（若有）；无未解释不一致。

## 完成检查

- 会话卡与计划/索引无未解释不一致
- 一句话进度与下一步可被下一手引用

## 不在此文件

- 擅自改里程碑目标
- 事件正文重写
- 门禁结论

下一步常接：`status-digest`；`handoff-pack`；`route-task`；`verify-gate`；`artifacts-append`。

## 工具锚点

对照：输入路径、输出路径、日志、表/schema 回读、diff、截图或命令输出。
完成前打开这些对照物；不合格则返工，不空口过关。
