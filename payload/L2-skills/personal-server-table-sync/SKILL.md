# 配表怎么同步到个人本地服

配表仓写入验收后，再到运行根导表并重载。两段都要做完。

## 何时用

改动已落在配表仓，验证环境是本机个人服。

## 怎么做

### 1. 定根与范围

1. 配表 Git 根、运行根、个人服目录、导表脚本、后台重载入口与服 id：从运行根文档（如 `agent.md`）读取，写入本轮范围卡。
2. 列出本批表 / 主键 / 列。本技能不定数值口径。
3. 成功标准：个人服 output 对应 json 已更新；重载（或项目约定的重启）后客户端读到本批新值。
4. 未确认不 `git push` 配表仓。源根与运行根搞混则停。

### 2. 源表写入（若尚未改完）

1. 配表仓按 `excel-com-write`：范围卡 → 沙盒 → diff → 获准 → 晋升 → 回读。
2. 声明只同步时，抽检关键主键后进导表。
3. 回读失败不进入导表。

### 3. 导表

1. 在运行根执行文档指定的导表脚本。
2. 退出码 0；本批相关 output 时间戳新于导表开始时刻。
3. 失败则读日志修源路径或导表工具后再跑。

### 4. 重载与验收

1. 按运行根文档重载个人服配置；热更无效则走文档中的重启；枚举 / 程序级变更按文档拉含改动的构建。
2. 客户端抽查本批新值。
3. 仍见旧值：先确认重载通道，再确认改的是已导出的表。

## 完成检查

- [ ] 源表已回读或确认只同步
- [ ] 导表成功且 output 已更新
- [ ] 重载或重启后抽查通过

## 失败回哪一步

- 路径不清 → 步骤 1
- 源表失败 → 步骤 2
- 导表失败 → 步骤 3
- 重载后仍旧 → 步骤 4
