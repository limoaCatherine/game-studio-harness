# 服务端 API 契约怎么冻

## 何时用

- 新接口定稿或协议变更
- 幂等/重试语义不清
- 前后端字段漂移要拉齐
- 支付/发奖类要防重放

## 怎么做

### 1. 列端点与字段

1. 每端点写：方法、路径、鉴权、请求/响应字段、类型、必填、真实字段名示例。
2. 错误码表：码、含义、是否可重试、客户端提示键；鉴权失败与权限失败分码。
3. 分页/过滤/排序约定统一；时间字段时区与精度写死；大包端点单独标大小上限。
4. 废弃字段标 deprecated 与移除版本；契约文档路径冻结，实现与文档双改。
5. 用契约文档（OpenAPI/proto 类别）导出字段表后，与实现 DTO 做一次字段名 diff；漂移列入修复清单。

**做到**：端点字段表与错误码表可对照实现；示例用真实字段名；大包上限与废弃策略已标。

**不合格**：示例用假字段名或文档路径空 → 回本步用真实名重写。

### 2. 定幂等与版本规则

1. 写幂等键位置（Header/Body）与重放窗口；支付/发奖/邮件可重试路径必须带键。
2. 同键连发两次，查库副作用计数=1；窗口外按规则视为新请求或显式拒绝。
3. 加字段：老客户端可忽略；删字段/改义：双读或升版本。
4. 限流响应与重试语义写清；版本规则 URL/Header/字段三选一为主写死。
5. 客户端提示键与本地化表键名抽查，缺键开客户端缺口，不在契约塞文案。

**做到**：幂等键位置与重放窗口写死；支付/发奖可重试路径均有幂等键；鉴权/权限分码。

**不合格**：可重试发奖无幂等键或鉴权权限混码 → 回本步。

### 3. 写契约测

1. 最小集：Happy、缺必填、越界/非法值、未鉴权；断言状态码与关键字段。
2. 幂等测：同一键重放两次副作用一次；破坏性变更附迁移与双读期测项。
3. 契约测与 mock 共用同一 schema；进 CI 且失败 exit≠0。
4. 用录制/回放或 schema 断言防止字段静默消失。

**做到**：契约测覆盖主路径与缺参且可自动红；幂等同键两次副作用一次。

**不合格**：测不红或 schema 与 mock 脱节 → 回本步修测。

### 4. 核对变更证据

1. 导出本里程碑字段集快照（路径+内容哈希）；变更须有 diff 文件。
2. PR/变更记录附契约 diff；文档/mock/客户端模型三处抽查一致或附不一致清单。
3. 通知客户端 Owner 有记录；紧急热变更临时双读+到期日在案。
4. 实现后跑相关 `ci-smoke`；回归日志路径归档。

**做到**：字段集快照、契约 diff、客户端通知记录可核。

**不合格**：缺 diff/通知/冒烟日志 → 回本步补证据（必要时回步骤 3）。

## 做到

- 端点字段表与错误码表可对照实现；大包上限与废弃策略已标
- 幂等与版本规则写死；契约测覆盖主路径与缺参且可自动红
- 字段集快照、契约 diff、客户端通知记录可核

## 工具锚

- API 契约 `.json` / OpenAPI 或 schema 文件
- 服务端工程与 `docker` / `docker-compose` 本地拉起日志
- 契约测命令输出与 `.harness/artifacts/` 下 diff

## 失败回哪一步

- 字段/错误码/示例假名、文档路径空 → 回步骤 1
- 支付可重试无幂等键、鉴权权限混码、版本规则多主 → 回步骤 2
- 契约测不红、幂等副作用>1、schema 与 mock 脱节 → 回步骤 3
- 缺 diff/通知/ci-smoke 日志 → 回步骤 4（必要时回 3 补测）

下一步常接：`ci-smoke`；安全面 `anti-cheat-hook-check`。
