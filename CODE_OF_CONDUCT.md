# Code of Conduct

Be precise. Argue about files, IDs, and evidence — not people.

## Standards

- No harassment, slurs, or personal attacks.
- Do not dump secrets, studio absolute paths, or live `mcp.json` into issues, PRs, or chat.
- Document each tool's native files and hook runtime as they actually are. Do not invent a live MCP server or a hook the host does not run.
- Give reproduce steps that use an isolate root, not a colleague's homedir.

## Scope

Issues, pull requests, discussions, and any space that uses this repository's name. The same rules apply to generated projections and Release comments.

## Enforcement

Maintainers may hide, edit, or remove content that breaks these rules, and may block repeat offenders. Report conduct problems through a private maintainer contact or a [private GitHub report](https://github.com/limoaCatherine/game-studio-harness/security/advisories/new) when the report itself would leak a secret.

This code of conduct is the project's own. It is informed by common open-source practice; the source of truth is this file.
