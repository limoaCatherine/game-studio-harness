# Shader/材质预算怎么控

## 何时用

- 关键字组合导致变体爆炸
- 移动端指令数/编译时间超
- 新效果要加关键字
- 材质球复制导致 needsUpdate 狂编

## 怎么做

### 1. 盘点变体

1. 列出 Shader 族与启用关键字组合；估或测变体数；分平台记指令数或 fill 重点指标。
2. 标热路径：过多分支、过多采样、频繁强制重编（needsUpdate/变体切换）。
3. 透明/overlay 层 fill 单独估算，不与不透明混报同一预算行。
4. 打开引擎 shader 变体统计或编译日志，按变体数排序找出最贵前 N 个族。
5. 材质球复制导致的重复关键字：扫「同 Shader 不同复制球」清单，标可合并候选。
6. 向用户索取目标平台画质档与可接受编译时上限；无数字不私定「移动大概多少」。
7. 对最贵 Shader 族打开变体列表，人工标「可删关键字」候选并评估外观影响。

**做到**：盘点表指出最贵族与原因。

### 2. 订白名单与上限

1. 写允许关键字集 + 变体/指令上限（分画质档）；超限项改到上限内再合入主包。
2. 新关键字准入：用途→影响面（哪些材质/场景）→批准人后再合入；先走准入单再开关键字。
3. 优先「少关键字、多参数」改造路径：能用参数切换的用参数，不新开关键字。
4. 移动档优先简单光照模型；自定义复杂 shader 必须有低端回退路径说明。
5. 精度策略：移动 fragment 默认 mediump/half，除非有文档证明需要 highp。
6. 把白名单与上限写入预算笔记并版本化，通知角色/场景/VFX。

**做到**：白名单与上限可执行；准入路径清楚。

### 3. 超标治理

1. 选项落地：合并关键字、降档、拆材质、砍功能；改完复测变体数与指令/编译时。
2. 移动档优先砍动态分支与多余采样；用 mix/step 替代热路径 if（按项目 shader 规范）。
3. 废弃关键字写下线日期与替代方案；到期未清的标债项。
4. 编译失败先修到目标档可编译，再谈画质取舍。
5. 对合并后的母材做代表场景回归：外观差异可接受或已申报取舍。
6. 打开 Overdraw/指令统计复核热区，确认治理不是只减了冷路径。

**做到**：超标项有处置与复测数；编译红修到绿再谈画质。

### 4. 笔记版本化

1. 汇总白名单、上限、准入流程、债项；打版本号通知角色/场景/VFX。
2. 下游新材质默认走白名单内关键字；出库检查勾「关键字∈白名单」。
3. 笔记存放路径写入任务备注，以路径文件为准，不单靠聊天截图。
4. 下一里程碑开始前重跑盘点，对比变体数是否回弹。
5. 与 `perf-budget-check` 对齐：shader 切片占帧预算的口径一致。
6. 抽查 3 个新合入材质：关键字∈白名单、用实例/参数变体而非整球复制。

**做到**：笔记可被制作引用；版本可回溯。

### 5. 制作侧执行检查

1. 角色/场景/VFX 新材质出库勾选：关键字∈白名单、未整球复制。
2. 发现野关键字：立即回盘点表加行并走准入或删除。
3. 移动档包体/编译时抽样：对比治理前后变体数。
4. 把常见「想加关键字」场景写成 FAQ 式改造建议（参数化替代），供制作自助。
5. 与 `import-validate` 约定：超白名单材质槽/关键字导入记 FAIL。
6. 预算笔记路径写入 TA 开工包。

**做到**：出库可勾白名单；野关键字有回流；笔记可达。

## 做到

- 变体/关键字盘点覆盖热路径 Shader 族；白名单与分档上限已定
- 超标已合并/降配并复测；新关键字准入路径明确
- 预算笔记已版本化并通知下游

## 失败回哪一步

- 无平台数字、最贵族未指出 → 回步骤 1
- 白名单空、私开关键字 → 回步骤 2
- 编译仍红、外观回退未申报 → 回步骤 3
- 笔记只在聊天、变体回弹 → 回步骤 4（必要时回 1 重盘）
- 出库野关键字 → 回步骤 5 回流盘点/准入

下一步常接：`perf-budget-check`。
## 加厚：变体 / 指令 / 采样预算

### A. 记账

1. 材质变体（keyword/permutation）数上限；超限合并关键字或拆画质档编译。
2. 纹理采样数、依赖贴图张数、全屏后处理道数分列；与 VFX 半透明填色分账。
3. 移动/低端：额外列「禁止的昂贵节点」（如过大花屏模糊链）。
4. 实例 vs 复制：同 Shader 不同参数走实例；禁止无意义整球复制爆变体。
5. 过热：实机或同等档看 GPU 时间；超切片先砍后处理再砍角色复杂材质。

### B. 落地

1. 预算表版本化；TA 评审新材质对照表。
2. 与 `vfx-budget-pass`/`perf-budget-check` 切片口径对齐，防双计。
3. 变更关键字须回归代表关卡编译时间与包体增量（若项目测）。

**工具类别**：引擎着色器分析、帧分析器、材质实例编辑器、CI 包体/编译报告。
## 检查清单（密化）
1. 变体数、采样数、后处理道数三行有数字与测量法。
2. 新材质评审对照表勾选；超限有合并方案。
3. 与特效填色分账；无双计。
4. 低端禁止节点列表非空。
5. 代表关卡回归记录可指。

## 工具锚点（live mcp.json）

- `materialpilot`：`app_get_status`/`app_get_capabilities` + tools/list 管变体
- `materialize`：launch-only。边界：仅 status / launch / open_file / list_recent（文件级）；不能遥控 GUI。人工在应用内完成绘制/绑定操作；MCP 负责开工具与指文件。Goal C 深化前勿假装有画笔 API。
- `gamedev-mcp` / `renderdoc`：关键字/变体实测
- `excelMCP`：白名单表
- **DoD：** 变体上限备忘版本化；超标派单；复盘日期写入。
