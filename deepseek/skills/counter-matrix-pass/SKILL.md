# 克制矩阵怎么填与校

## 何时用

- 元素/兵种/阵营克制需定稿
- 克制循环导致唯一解或免疫岛
- 公式乘区与克制表不一致
- 新单位加入破坏旧平衡或 UI 要同源展示

## 怎么做

### 1. 定义克制轴与作用点

**做**
1. 选定轴类型（元素/武器/兵种/阵营）；列类别 ID 与显示名；写互斥规则（单位单属还是双属）。
2. 声明作用点：伤害乘区 / 抗性修正 / 控制时长 / 其他修饰；作用点必须能挂到 damage-formula 插入层。
3. 与 attribute-framework、damage-formula 的修饰项名对齐；缺项先补公式/属性再填矩阵。
4. 写「本版不做」的轴（如只做元素不做兵种），避免后期偷加第二轴无文档。
5. 给 2 套轴粒度（粗类少 / 细类多）+利弊，用户选定后再建矩阵。
6. 冻结本版类别集合；增删类别需显式变更并重跑循环检查。
7. 类别 ID 与单位表字段、UI 图例键做一次全文一致性搜索；漂移名列入替换计划。

**做到**：轴类型+类别 ID 集合冻结；作用点可挂 damage-formula 插入层；本版不做轴显式；失败→回本步 改 类别 ID 或作用点声明

### 2. 填写矩阵关系

**做**
1. 建 N×N：每格显式克制/被克/中性/免疫，并写允许强度档字段名（不编具体倍率故事）。
2. 免疫与不对称关系写成显式格子。
3. 双属单位写死聚合规则：取最高克制 / 乘算 / 平均 / 主属优先；口头约定不算。
4. 中性格填「中性」字面值，不留给程序默认。
5. 矩阵主键用类别 ID，与 UI 图例、单位表字段同一套。
6. 产品表落矩阵：沙盒 `excel-com-write`；表头含进攻类、防守类、关系、强度档；落盘后核对这四列与类别 ID 一致（sheet 名以项目表为准）。
7. 填矩阵时对「免疫」格额外写反制手段槽（技能/状态/规则）；空槽标风险。

**做到**：N×N 每格含关系+强度档字段；双属聚合规则写死；空格=0；表头进攻类/防守类/关系/强度档可指 sheet.col；失败→回步骤 1 改 类别集合或矩阵格/聚合规则

### 3. 检查循环与强度

**做**
1. 扫过短强克制环（如 A>B>C>A 且档过高）、单类克制全域、无反制免疫岛。
2. 对照公式钳制：克制强度叠加后是否挤爆上下限；超阈则降档或改作用点（改乘区→抗性等）。
3. 给调整选项：改关系格 / 改强度档 / 改双属聚合 / 拆免疫为高抗；每选项写影响面单位列表。
4. 新单位加入时重跑本检查；只改单位表不重跑视为未完成。
5. 记录问题清单：类型、涉及类别、建议选项；请用户选定后再改表。
6. 循环检查结果与强度档变更写入同一诊断页，供用户一次拍板。
7. 缺项目数字/档位时向用户索取，标假设的条目不得当事实引用。

**做到**：短环/免疫岛/破钳问题清单有选项；强度叠加不破公式上下限；用户选定记录在案；失败→回步骤 2 改 关系格或强度档字段

### 4. 映射到公式与展示

**做**
1. 矩阵输出映射到公式修饰项名与表字段（`DamageFormula` 修饰列 / `CounterMatrix` 强度档列）；UI 图例、战斗内克制箭头用同一 ID。
2. 全文搜索旧克制硬编码；残留列入影响面并清掉或改读表。
3. 冻结本版类别集与作用点；变更走 diff 晋升 `tunable-table-diff`。
4. 与客户端展示、跳字是否显示克制倍率确认一致；不一致先修同源再调表现。
5. 输出：矩阵表路径、修饰项名、UI ID、已知残留风险。
6. 映射完成后抽 3 个单位走读：进攻类×防守类→修饰项→跳字是否同源。

**做到**：修饰项名=公式字段；UI 图例键=类别 ID；抽 3 单位进攻×防守→跳字同源通过；失败→回步骤 3 改 强度档或矩阵映射字段

下一步常接：回写 `damage-formula-pass`；单位表晋升 `tunable-table-diff`。

## 细则

### A. 作用点与公式插入层对照

1. 打开 `damage-formula-pass` 顺序表，确认克制修饰落在哪一层：推荐显式层名 `mul_counter` 或 `res_counter`，禁止塞进未登记暗乘。
2. 对照属性框架：若克制吃「抗性」类主键，主键必须已存在；缺则先开 `attribute-framework` 扩展位。
3. 控制时长类克制：写清是乘 `cc_duration` 还是加减 tick；单位与 `hitstun_ticks` 一致。
4. 检查：用验算槽只改克制档、其他输入不变，输出变化方向符合 `strong/weak`。
5. 不合格：输出不变或方向反了 → 回映射字段，不调无关系数。

### B. 矩阵扫描可执行清单

1. 导出 N×N 为边表：`atk_class,def_class,relation,tier`；用表筛选 `relation=strong` 构图。
2. 短环检测：长度 3～4 且 `tier` 全高 → 记入诊断，选项含降一档或改一边为 neutral。
3. 免疫岛：`immune` 且 `counterplay_slot` 空 → 必给技能/状态/规则槽或降为高抗。
4. 全域碾压：单 `atk_class` 对 ≥70% `def_class` 为 strong → 标唯一解风险。
5. 新单位入表后重跑本清单；CI 或手工勾选记录日期与矩阵版本。

### C. UI/跳字同源

1. UI 图例键 = `class_id`；跳字是否显示克制倍率与服务器修饰同源开关写死。
2. 抽 3 对进攻×防守：日志修饰项名、跳字、图例三处 ID 一致。
3. 观战/录像若有独立展示通道，声明是否复用同一矩阵读表。
4. 残留硬编码：`rg` 旧元素名/中文克制词；清完才冻结。
5. 变更晋升：`tunable-table-diff`；高风险格绑定必测对局用例。
