# 产销地图怎么建

## 何时用

- 新货币/材料上线前要登记产销
- 库存异常需定位产销通道
- 上限与投放不对齐或活动 Source 未登记
- 给通胀/物价提供净流量视角

## 怎么做

### 1. 枚举实体

**做**
1. 列实体：展示名、canon 名、持有上限、绑定（绑角/绑账/可交易）、是否限时、展示位。
2. 按用途分组：软通货/硬通货/材料/体力；限时货币单独组并写过期处理字段。
3. 与 canon/属性表冲突则并列「旧|新|处置」请用户裁。
4. 声明本图范围：哪些实体进本版地图、哪些延后；延后写理由。
5. 向用户索取上限与绑定规则缺省值；不猜。
6. 输出实体表：实体、canon、上限、绑定、限时?、分组。
7. 实体分组与商店/背包展示位对照；有展示无实体或有实体无展示均标断裂。

**做到**：实体清单完整可指 ID；限时过期字段有着落；命名与表主键一致；失败→回本步 改 实体清单或过期字段

### 2. 列出 Source 与 Sink 通道

**做**
1. 每实体列 Source：玩法投放、商店购买、邮件/补偿、活动、GM；写频率字段与表字段 sheet.col。
2. 每实体列 Sink：商店消耗、打造、升级、过期、销毁；写触发与表字段。
3. 专门扫邮件/补偿/GM/客服/兑换码旁路；未登记标红。活动限时 Source 写起止字段。
4. 通道用稳定 ID；通道用稳定 ID 并写期望获取节奏字段。
5. 查无限环：A 兑 B 兑回 A 且期望净增>0；有则标「无限累积」风险。
6. 输出产销表：实体、通道 ID、Source/Sink、频率、表字段、旁路?。
7. 旁路通道扫完再扫主通道一遍，防止「先主后旁」漏登记补偿。

**做到**：主通道 Source/Sink 无空白；旁路显式；无限环已标边；失败→回步骤 1 改 实体定义或 Source/Sink 边

### 3. 净流量 vs 上限

**做**
1. 定义净流量：ΣSource期望 − ΣSink期望（日/周窗口，空槽公式，不填样例故事数）。
2. 对照持有上限：窗口净流入×N 天可顶满则标顶满风险并写 N 的计算字段。
3. 标风险实体：净正无强 Sink、Sink 仅靠过期、Source 含不可控旁路；单位不一致先统一。
4. 健康指标槽命名：窗口净流入、顶满人数占比、关键 Sink 参与率（与监控对齐命名，不编造阈值）。
5. 检查金钥类 Sink 是否随水龙头增速缩放；不缩放标「物价阶段性失效」风险交 price-curve。
6. 净流量单位与上限单位统一后再投影顶满天数。
7. 缺项目数字/档位时向用户索取，标假设的条目不得当事实引用。

**做到**：净流量字段可算（窗口公式可见）；风险实体可指；健康指标槽命名与监控一致；失败→回步骤 2 改 产销边或净流量公式

### 4. 映射字段并交付

**做**
1. 整理实体+产销+风险为可引用地图文档；风险实体建议 inflation-stress / price-curve-pass。
2. 改投放/上限字段：列 sheet/列，走 `excel-com-write` 沙盒，晋升 `tunable-table-diff`。
3. 邮件旁路通道 ID 与 reward-mail-check 对齐；缺失则两边同时补。
4. 冻结本版实体集与主通道 ID；新增通道必须登记再上线。
5. 输出：地图路径、风险清单、改表字段表。
6. 交付地图时附风险实体→建议下游 Skill 映射行。

**做到**：地图可被下游引用；改表字段清单齐；邮件旁路与 reward-mail 通道 ID 一致；失败→回步骤 3 改 净流量/风险或旁路登记

下一步常接：`inflation-stress` / `price-curve-pass`；邮件旁路 `reward-mail-check`。
