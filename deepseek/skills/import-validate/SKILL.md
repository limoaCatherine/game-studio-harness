# DCC→引擎导入怎么验

## 何时用

- 已命名导出物要进引擎
- 缩放/轴向/材质槽异常
- 动画切段丢失或 LOD 链断
- 覆盖旧资产需声明范围

## 怎么做

### 1. 对齐导入预设

1. 确认本批命名阻塞已清（或不受影响资产已隔离）；命名未清的资产先隔离再导。
2. 打开项目导入预设：单位、轴向（前向/上向）、切线空间、动画采样率、材质/贴图搜索路径、是否生成碰撞。
3. 列出目标引擎路径；若覆盖旧资产，先写覆盖范围与回滚方式。
4. 向用户确认压缩（Draco/Meshopt 等）是否启用；解码器缺失必须显式失败，不静默变粉红。
5. 预设字段抄进任务备注；用字段清单对齐，不靠「跟上次一样」。
6. 分类型预设（角色/场景/UI 图）分开选用；用错预设先换对再导。
7. 导入后立即看 Inspector/细节面板：缩放、材质槽数、动画切段列表与预期一致。

**做到**：预设字段已写入任务备注；覆盖范围/回滚显式。

### 2. 机检

1. 查导入后缩放≈1、旋转无异常 90°、网格可读；Console/日志无 Missing 网格。
2. 材质与贴图引用存在；缺贴图记 Missing 路径；槽名与 DCC 一致；落到 DefaultMaterial 记 FAIL，不当成功。
3. 贴图：POT、压缩格式、尺寸是否≤档位（档位向用户索取）；超预算记 Size。
4. 动画：切分名、帧率、时长；与 `anim-set-checklist` 的 anim_id 对齐；丢切段记 FAIL。
5. LOD 链：同骨架、级数齐、命名后缀统一；缺级记 FAIL。
6. 材质槽数超白名单记 FAIL，不静默降级；影响骨数超蒙皮上限同样显式失败。
7. 跑项目机检脚本或检查清单：FAIL/Missing/Size 写入机检表，红项必须有解释或阻塞标签。

**做到**：机检表无未解释红项；缺依赖显式。

### 3. 代表场景试播

1. 关键网格拖进代表光照场景：看比例相对场景道具、法线是否反、接缝黑线。
2. 播关键动画：脚滑、关节塌陷、穿模；已挂事件则看 Notify 是否触发（日志或调试点）。
3. 切 LOD/画质档：材质是否丢失、挂点是否还在、切换是否狂闪。
4. 角色：T/A-pose 与绑定姿态一致；武器 Socket 挂测试件看漂。
5. 场景模块：邻接两件拼接，碰撞盒是否匹配可行走净空。
6. 问题分类：回 DCC / 改预设 / 改引擎材质实例；半导入资产移出可引用集。
7. 试播问题写回流单：`现象 | 责任面(DCC/预设/材质实例) | 复现步骤`。

**做到**：试播问题可回流；无「半导入当可用」。

### 4. 固定可引用路径

1. 写最终资产路径与依赖清单（网格、材质、贴图、动画、骨架）；旧路径标废弃或重定向表。
2. 机检或试播失败的资产留在隔离集；修好再导，或移出本批。
3. Prefab/表改为新路径后做一次 Missing 扫描。
4. 通知下游（绑定/动画/关卡）新路径与覆盖范围。
5. 缓存/复用：同模型避免重复解码占用；实例化而非改共享原型（按引擎惯例）。
6. 把可引用路径列表贴进任务备注，作为下游唯一入口。
7. 对可引用集做 Content Browser / 资源引用扫描：断引用与旧路径重定向表对齐，未对齐项移出集。

**做到**：下游拿得到稳定路径；失败资产未混入可引用集。

### 5. 回归与通知

1. 本批可引用路径列表发给绑定/动画/关卡；旧路径废弃说明同步。
2. 对覆盖资产做一次「打开旧存档/旧 Prefab」检查：断引用是否已重定向。
3. 机检脚本若有：把本批纳入回归集，下次导出自动跑。
4. 记录本批用过的导入预设名与版本，防口头漂移。
5. 失败资产单独目录隔离，与可引用集分开放。
6. 抽查 Console 无新增 Missing/Error 后再标本批完成。
7. 回归清单勾：通知已发、旧 Prefab 已开验、失败隔离路径可指；任一项空则继续补齐。

**做到**：下游已通知；旧引用已处置；失败隔离。

## 做到

- 导入预设（单位/轴向/搜索路径）明确；机检无未解释失败；Missing/Size 有记录
- 关键网格与动画试播通过；LOD/材质在切档后可用
- 最终路径与依赖可被 Prefab/表引用；失败资产隔离

## 失败回哪一步

- 命名未清硬导、预设混用、缩放/轴向批错 → 回步骤 1（命名先 `export-naming-gate`）
- 机检红项未解释、DefaultMaterial 假绿、搜索路径空 → 回步骤 2（必要时回 1）
- 试播才爆 Missing、半导入标可用 → 回步骤 2 补机检，再回步骤 3
- 失败资产混入可引用集 → 回步骤 4 移出并重导
- 旧 Prefab 仍断、通知未发 → 回步骤 5（必要时回 4 补重定向）

下一步常接：网格类 `lod-budget-pass`；事件 `anim-event-hook`。
## 加厚：导入预设与机检绿灯定义

### A. 导入前契约

1. 单位、轴向（前向/上向）、缩放（期望 1）、材质搜索路径、是否导入碰撞、是否导入 LOD、法线导入方式（保留作者 vs 重算）写入命名的导入预设；批内禁止混用未记录预设。
2. 自定义碰撞：命名前缀与渲染网格对应；关闭「自动生成碰撞」叠加，防双碰撞。
3. 蒙皮：骨架映射/Avatar 正确；皮肤权重上限与 DCC 剪裁一致；形态键列表非空（若有）。
4. 法线：导入后硬边黑缝/翻面 → 优先查是否被重算法线毁掉作者法线，再查 DCC 光滑组。
5. 动画导入：指定已有骨架，不新建重复骨架；Root Motion 开关与 Clip 矩阵一致。

### B. 机检与可引用集

1. 机检失败分类：Missing 依赖、尺寸超标、DefaultMaterial 假绿、骨架不匹配、LOD 未进——每类处置路径写清。
2. 试播：网格转一圈 + 关键动画各播一次；半导入不得标可用。
3. 可引用集：仅机检+试播通过路径；失败进隔离目录；下游只拿可引用列表。
4. 旧预制体打开验断引用；重定向表与改名表对齐。
5. Console：本批完成后无新增 Error；Warning 逐条解释或建债。

**工具类别**：引擎导入器/互换管线、内容浏览器引用扫描、CI 机检脚本、版本库。

## 工具锚点（live mcp.json）

- `gamedev-mcp`：导入预设/Inspector/Console
- `meshlab`：导前格式核验
- `everything-search`：依赖/贴图路径
- `ffmpeg`：动画试播录像（可选）
- **DoD：** 机检表无未解释红项；试播通过；可引用路径列表已通知下游。
