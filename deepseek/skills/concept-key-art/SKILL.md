# 概念主视觉与设定怎么画

## 何时用

- 角色/场景要开概念进 3D；Brief 不足外包不知保什么
- 主视觉需对齐风格锚点；只有气氛图、缺可建模信息

## 怎么做

### 1. 写 Brief（锚点硬抄）

1. 打开 `style-anchor` 职种切片、Hex 表与拒收标准；把必保剪影/色/材质记忆点抄进 Brief「必保」栏（文档表或 Figma Brief 页）。
2. 在设定 / 支柱文档里检索敌我识别、职业剪影、威胁色语义、关键道具可读点（路径以项目为准）。
3. 写成功标准：缩到约定像素高（向用户索取，如 128px）仍可识别类型/阵营；并列非目标（不做表情全集等）。
4. 无锚点或 Empty 块：停→补 `style-anchor`；Placeholder 标依赖缺口；用锚点正文，气氛板只作参考注。
5. 参考图每张写「学什么/不学什么」≥2；交付物清单勾选：主视觉、三视、分解、材质标注、挂点示意。
6. 两名执行者复述 Brief 必保三项；不一致则加形状/色语义词。

**做到**：Brief 含禁区 ID、Hex/记忆点、缩图可识别标准、交付勾选；有锚再开工绘。

### 2. 剪影/色块选型（缩图墙）

1. 在 Photoshop / Clip Studio / Procreate 出 ≥3 方向小剪影或色块；导出到 Figma/文件夹选型墙，**同缩放并排**比可辨度。
2. 对照锚点拒收标准逐条淘汰；淘汰记录：`candidate_id|hit_reject_id_or_pillar|note`。
3. 去饱和灰度与单色块各看一遍；记忆点仍在才允许加细节。
4. 与已有角色/敌人缩图并排撞型检查；撞型改外轮廓，不只改配色。
5. 用户锁定后写：入选 id、淘汰列表、锁定人、日期；定稿前先锁剪影/色块，高细节与滤镜放在锁定之后。

**做到**：≥3 向有记录；锁定含禁区/支柱引用；缩图可辨结论落盘。

### 3. 正稿、三视与色彩空间

1. 主视觉标注材质分区、关键道具、主配色块（旁注 Hex）；图边写头身比数字（非仅感觉）。
2. 出正/侧/背三视或 turnaround；装备拆分图；模糊区补结构线或显式「3D 自决」批准项。
3. 头、手、武器刃面等绑定敏感区给足形体体积，避免只有气氛光影。
4. DCC 文档色彩：工作空间与导出色彩空间（交付扁图常用 sRGB——以管线为准）；检查软打样与明显色溢。
5. 状态变体（破损/觉醒）若本版需要：变体不丢识别特征，列与基础态差异点。
6. 对照 Brief 缩图复验；失败改剪影/色块，用结构与色块保识别度。

**做到**：三视够建模；头身比与 Hex 在图上；色彩空间符合管线；猜点=0 或已批 3D 自决。

### 4. 交付检查器与版本落盘

1. 跑交付检查清单：`name+version`、分层源（.psd/.clip/.procreate）、扁导出、分辨率、色彩空间、透明通道、文件打开无缺字体。
2. 路径写入给 `character-asset-checklist` / `env-asset-checklist` 的输入栏；任务备注写「可开 3D」+ 概念版本号。
3. 与锚点冲突单独呈报变更请求；旧版移 `archive/` 或标 Deprecated；正式句变更走升版。
4. 外包包强制附：Brief、禁区摘录、拒收标准、定稿剪影——不只发气氛图。
5. 未参与绘制者看三视：仍需口头解释的部位→回步骤 3 补线。
6. 道具/武器影响绑点则补挂点空位名示意。

**做到**：检查清单全绿；资产流程可引用路径；未偷改锚点；第三方可读通过。

## 做到

- Brief 含禁区与缩图可识别标准；≥3 向选型锁定且淘汰理由可查
- 三视/分解够建模；头身比与 Hex 在图；色彩空间与源/扁导出齐
- 「可开 3D」已写；未静默改锚点

## 失败回哪一步

- 复述漂移、无锚点、气氛板冒充锚点 → 回步骤 1（先补 `style-anchor`）
- 缩图墙不可辨、全员触拒收 → 回步骤 1 改 Brief 必保后再选型
- 「建模师还要猜」、缺比例/三视 → 回步骤 2 或 3 补结构
- 检查清单红、未落版口头改设定 → 回步骤 3/4 修文件后再打「可开 3D」

下一步常接：`character-asset-checklist` / `env-asset-checklist`。
## 生产稿与宣发分流

### A. 生产设定包

1. 三视图/turnaround 含比例尺与关节可读；装备穿脱关系清楚。
2. 材质分区/硬软面/颜色 ID 备注给 3D；禁改记忆点清单（剪影/主色块）。
3. 武器配件分件示意；期望挂点与可动范围。
4. 场景概念：地标、主路径视线、门高/栏杆尺度（米制）、模块边界。
5. 两名执行者读同一 Brief 应能做出同方向——抽测问询记结果。

### B. Key Art 分轨

1. 宣发 Key 与生产稿分目录/分命名；3D 只跟生产稿路径。
2. Key 可夸张光影；生产稿必须可拓扑可绑/可模块。
3. 版本号与选型决议写侧记；落选案归档理由。
4. 外包 Brief：尺寸、分层、禁改、锚点引用、面数/风格档提示。

**下一步**：角色→`character-artist`；场景→`environment-artist`；锚点回写 `style-anchor`。
## 检查清单（密化）
1. 生产包：三视图、材质注、分件、禁改、版本号齐全。
2. Key/生产分轨抽查路径不交叉。
3. 场景稿含米制与主视线。
4. Brief 抽测：第二人能开做。
5. 落选案理由已归档。
